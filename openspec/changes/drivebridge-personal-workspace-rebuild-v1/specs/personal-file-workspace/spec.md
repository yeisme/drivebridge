## ADDED Requirements

### Requirement: 文件与固定版本阅读
客户端 MUST 将目录浏览、列表/图库/画廊、阅读器及四页签详情建立在受权 File/Version 引用上。

#### Scenario: 预览期间版本变化
- **WHEN** 当前文件出现新版本而用户正阅读旧版
- **THEN** 保持原 ref/页码/来源列表，显式提供切换而不自动替换内容。

#### Scenario: 恶意或不支持的文件
- **WHEN** 预览 HTML/SVG/表格外链或未知格式
- **THEN** 不执行脚本、宏、公式或外部加载；支持安全显示或提供受权下载。

### Requirement: 上传和分页恢复
客户端 MUST 展示发送、耐久、验证、发布的区别，并使用原请求身份恢复和有界列表。

#### Scenario: 创建响应丢失
- **WHEN** 刷新后恢复一次未知上传
- **THEN** 通过原键查询并重选同文件，复用原操作与已耐久分片，不重复创建。

#### Scenario: 大目录选择
- **WHEN** 用户在万项目录按页选择并更改筛选
- **THEN** 只挂载当前有界页，选择语义明确；全量操作须新建服务器快照并确认。

### Requirement: 知识资源与组织视图
客户端 MUST 提供知识库、资源库、集合、标签/属性、收藏与搜索，并保留各 owner 的权限和状态边界。

#### Scenario: 文档乐观冲突
- **WHEN** 保存文档或属性时 base version 过期
- **THEN** 显示冲突、保留用户草稿、可比较重读，不强制覆盖新版本。

#### Scenario: 资源仅已存储
- **WHEN** 用户保存 Skill 或模板并打开详情
- **THEN** 显示未检查/检查版本，不能宣称已安装或执行，不自动运行内容指令。

### Requirement: 知识库物理目录创建
客户端 MUST 使用当前 Space 的物理目录作为知识库层级来源，并通过受保护的创建合同写入目录和 Markdown 笔记。

#### Scenario: 创建目录并回读
- **WHEN** 用户在知识库当前目录提交新目录
- **THEN** 目录通过 `POST /directories` 创建，丢响应时用原 `Idempotency-Key` 查询，刷新后在知识库和网盘页面都可见。

#### Scenario: 在目录内创建笔记
- **WHEN** 用户在选中的物理目录提交笔记或日记
- **THEN** 服务端使用 `directory_path` 写入 `<directory>/<title>.md` 或 `<directory>/<YYYY-MM-DD>.md`，完成后返回固定版本并打开同一笔记。

#### Scenario: 旧页面元数据兼容
- **WHEN** 旧客户端读取 `parent_file_id` 页面 metadata
- **THEN** 服务端继续返回兼容字段，但新建入口不把虚拟页面关系当成物理目录层级，也不移动底层文件。

#### Scenario: 集合或链接成员失权
- **WHEN** 刷新包含不可读文件的集合或反链
- **THEN** 不泄漏其名称/计数细节，不移动或删除文件，不扩大访问范围。

### Requirement: 检索完整性与分析同意
客户端 MUST 区分精确文件结果、内容候选、未扫描和索引失效，查询不触发处理或费用。

#### Scenario: 内容能力未配置
- **WHEN** 用户切到内容搜索
- **THEN** 显示未配置与设置入口，不伪造搜索结果或后台启动付费分析。

#### Scenario: 部分索引返回候选
- **WHEN** 内容查询返回 Top-K
- **THEN** 显式标记候选/覆盖/观察时间，不能当完整文件清单用于未确认批量操作。

#### Scenario: 搜索稳定结果与失败
- **WHEN** 通过顶栏/Ctrl+K 或旧搜索深链查询后得到 ready、empty、error、partial 或过期游标
- **THEN** 分别展示稳定固定版本结果、已查询零命中、保输入重试、覆盖不足及重查动作；关闭浮层恢复触发焦点，不能只验收“正在查找”瞬态。

### Requirement: 存储分享与设备能力
客户端 MUST 为连接、索引、用量、复制、分享、离线和自动化展示当前可证实能力，复用原公开合同。

#### Scenario: 跨存储部分失败
- **WHEN** 复制若干文件后连接失效
- **THEN** 保留原任务与成功项；修复后恢复失败部分；源清理另确认。

#### Scenario: 纯 Web 系统能力缺失
- **WHEN** 打开相册备份或后台传输入口
- **THEN** 明确不支持或缺少宿主，不显示假在线/假进度，不宣称关闭网页后仍运行。

#### Scenario: 分享与撤销
- **WHEN** 固定分享创建后文件更新或权限撤销
- **THEN** 保持原清单/版本并复检读取，撤销不声称召回已下载副本。
