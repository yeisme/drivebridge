# 本机与远程边界

本机 viewer 仅转发固定动作到同一 state 的 0600 owner socket。保持 Host、Origin、CSRF、启动链接时效与本机 root 范围约束。目录通过独立可选字段演进；旧 List、配置、引用和输出保持兼容。

文件操作复用已存在的 provider 和传输队列，预览复用 SDK 中的局部转换器。remote share 的副本和策略由本机服务记录，分享权威与接收方访问检查仍归远程服务。固定交付保存确切引用，持续共享显示更新时间和失败；撤销不删除用户源文件。

回滚停用新增页面入口与私有动作，保留原配置、连接密钥、操作、引用、远程副本和分享信息。验证使用本机 alias provider 与远程 fixture 的真实进程，不能以 fixture 通过宣称真实云服务已启用。详细运行与恢复见 docs/local-file-experience.md。
