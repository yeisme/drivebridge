# 统一交付中心与可定制分享

DriveBridge 的分享 API 目前只支持有限期限，分享页没有展示定制能力，传输与产物入口也缺少统一交付语义。本变更增加 `days=0` 永久分享、受控展示配置和兼容的永久状态字段。

## 目标

- 保留现有 `/shares` 路径和有限期限行为。
- 允许明确创建永久分享，并让撤销成为其失效方式。
- 允许分享页使用受控主题、字体、品牌色、Logo 引用和欢迎语。
- 继续校验指定用户 ID 的租户成员关系。

## 兼容与回滚

新增字段均为可选；`days=0` 是对现有请求字段的兼容扩展。数据库使用可空/默认安全字段并由 GORM 自动迁移。若需回滚，关闭前端永久与展示配置入口并回退服务端提交；既有有限期限分享继续可读。
