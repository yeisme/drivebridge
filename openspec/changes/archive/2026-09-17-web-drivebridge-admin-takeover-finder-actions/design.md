## Decisions

确认输入默认目标用户名，用户可以切换至自己的 Key。只有后端声明可接管时显示职责清单和确认复选框；不将名称当作登录身份。服务端失败保留输入，409 要重新取得影响。

FinderMenu 用现有 React Portal 避免侧栏裁切，按视口约束位置，支持上下键、Home/End、Escape、Shift+F10 和触屏更多按钮。滚轮及外部点击关闭菜单，程序自动滚动不关闭刚打开的菜单。操作只展示现有服务能力，文件夹没有虚构的递归删除或重命名。

新建目录默认单层名称，可显式开启多级相对路径并选择创建后打开；拒绝绝对路径、空层级、点目录及控制字符。文本文件通过同一上传系统保存，后台传输状态继续可见；错误不关闭编辑器，重名不覆盖。受管空文件保持真实零字节；本机模式明确要求内容并提示后台保存，不冒充已完成。

元数据只展示实际路径、大小、类型、更新时间、版本/文件标识、来源和当前目录页的计数，不编造递归大小。切换空间/目录时关闭未提交表单并中止创建请求，旧请求不能污染新的工作区。

## Validation

复用 Go fixture、Vitest 和 Playwright：账号用户名确认/接管，目录层级校验，新建非空和空文件，同名失败后继续重命名，键盘菜单、窄屏菜单边界及元数据；原图片预览与分享流程保留。测试及截图由 scripts/check.py 保存，截图不包含密钥输入。
