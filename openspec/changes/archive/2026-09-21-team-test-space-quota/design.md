# 设计与恢复边界

创建团队网盘仍需租户管理权限，负责人须为活跃租户及团队成员；允许选择本人。space-quota 仅授权管理员调用，正整数校验，条件更新确保新值不低于 used + reserved，受团队版本和审计事务约束。普通团队成员和 Agent 不可修改。

开发恢复使用 checkpoint_demo.py 对活动实例执行 SQLite 在线备份，复制私有状态至用户目录；不停止源进程、不在仓库存放实例密钥。drivebridge-demo-resume 仅允许 loopback 体验环境，对复制后的状态逐版本复制存储字节并校验解密后的 SHA-256 与大小。成功才更新该副本的连接，磁盘对象目录支持重启恢复。准备失败保留原入口。初次切换前核对源版本集合，避免备份期间新文件被遗漏。

默认不启用 RequireExplicitAdminRead，保持已有部署的管理员只读合同；恢复命令显式启用，管理员角色本身不授予内容读取权，owner/custodian/viewer/editor 和获批读取权限按原合同处理。该开关只用于本次本地体验，不改变公网实例。

回滚：切换前可丢弃未启用副本；切换后不直接回指旧数据（会丢失新写入），先对新状态及 objects 生成完整 checkpoint，再复用旧二进制/恢复入口验证后切换。源实例与备份保留，不自动清理。真实云商、统一组织平台和外部邀请不在范围内。
