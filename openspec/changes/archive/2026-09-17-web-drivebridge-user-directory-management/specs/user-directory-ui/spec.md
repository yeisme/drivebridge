## ADDED Requirements

### Requirement: 用户筛选和准确的 Key 详情
客户端 SHALL 提供状态、角色、团队和用户/Key 查询，显示真实 Key 元数据计数或明确不可见状态，并打开所选用户详情。

#### Scenario: 查看其他用户
- **WHEN** 用户选择某行的 Key 详情
- **THEN** 展示该用户的可见元数据，不展示他人明文或跳到无关 Key 列表

### Requirement: 确认账号操作影响
客户端 SHALL 使用服务端操作影响与版本执行冻结、解冻、删除归档及恢复，不模拟权限或跳过冲突。

#### Scenario: 删除账号
- **WHEN** 管理员点击删除并归档
- **THEN** 展示停止访问与凭据失效的影响、文件保留说明，经过身份验证和确认后更新列表

### Requirement: 管理弹窗适应视口
客户端 SHALL 保持内外面板宽度一致，页签可换行，表单在桌面及移动端均不被横向裁切。

#### Scenario: 窄屏管理
- **WHEN** 在 390px 宽窗口打开管理中心
- **THEN** 对话框内只有必要的纵向滚动，按钮与输入框完整可达
