## Why

管理与授权中心内外层宽度冲突，导致表单和页签横向被裁切。用户目录缺少筛选与具体管理入口，无法区分零个 Key 与无权查看，需要与真实服务对齐。

## What Changes

- 统一管理对话框及面板宽度，只保留纵向滚动，页签随窗口换行。
- 新增用户状态、角色、团队筛选及 Key 查询/元数据详情。
- 在对应行提供冻结、解冻、删除归档和恢复；先请求影响，再验证身份及确认。
- 旧服务保留基础目录并提示不可用能力，窄屏使用用户卡片。

## Capabilities

### New Capabilities
- `user-directory-ui`: 可筛选的用户目录和账号生命周期界面。

## Impact

split-owner：客户端只消费 backend-server/drivebridge 的合同，不拥有用户状态和权限。继续保留团队入口与管理中心。没有新增组件库、浏览器密钥持久化或真实部署。
