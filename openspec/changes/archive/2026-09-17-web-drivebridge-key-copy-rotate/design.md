## Decisions

复用 WorkspaceDialog 和现有按钮，普通复制按点击向服务端取回，成功复制后不保留 React 密钥状态；查看、轮转和剪贴板失败恢复才暂存到面板。面板默认密码框，用户可显示并手动选取；关闭或切换身份/访问上下文后销毁。列表遵循服务端能力，旧 Key 无密文时提示登录补齐或轮转。

原生 select 和 input 使用统一 CSS，不替换键盘、读屏及移动端选择器。1100px 以下 Key 行折为卡片，操作按钮可换行，不依赖横向滚动。

## Compatibility and rollback

新增可选目录字段及 HTTP 路径，旧 metadata ID 保留。明确替代“关闭后不可再取”的旧用户 Key 产品行为，签发管理员不获得其他用户的取回权限。可回退本次客户端和后端代码，已有哈希认证继续可用，无删除迁移或废弃窗口。

## Validation

复用 Playwright：真实 API 下两次复制、查看遮罩、轮转、刷新后取回、其他会话失效、剪贴板拒绝恢复。截图只在密钥面板关闭后保存，覆盖 1440、868、390 宽度；用原有 scripts/check.py 保留成功和失败证据。另运行现有 Vitest 和构建。
