## UI 合同

继续使用 Precision Pine 语义令牌与 Base UI 原语。桌面控件 32px、触屏至少 44px；浮层宽度不超过视窗减 32px，内容可内部滚动。更多筛选不占正常文档流，打开/关闭不改变下方指标位置；日期范围保留在触发器旁，快速日期与自定义日期使用同一状态。

审计用户名来自当前已授权的治理投影或本人资料，机器人名称来自当前已可见的授权列表；不调用全局用户目录补全名字，不将 caller 当作认证身份。找不到名称时显示身份类型与短 ID，完整 ID 通过提示或复制读取。已知 action 显示中文，未知值显示“其他操作”，原 action 保留在提示和导出。机器协议不翻译。

工作区浮层每个入口图标与文字左对齐，空间选择独占一行；体验身份区域标签在上，选择器与确认按钮同排，宽度不足时自然堆叠。退出位于底部分区。所有菜单支持 Escape 与焦点恢复。

Key 表格采用独立 cell 布局；名称是自然高度的 surface，不能继承普通单行按钮宽度。行内仅复制、详情、更多，轮转/禁用/启用/吊销/删除/重命名在下拉菜单中保留原确认。搜索只有一处，宽表只在自身容器内滚动。

个人设置保留现有主题、密度、减少动效和资料保存能力。“使用偏好”仅指删除用户标注的右侧说明卡，不删除这些实际功能。右侧改为大纲；窄内容区在顶部横排。点击滚动当前内容区并聚焦分区标题，不覆盖现有 hash 路由或未保存表单。

## 验收

1186×1040 复现六处问题，追加 1440、957、390px 深浅主题。断言高级筛选展开前后指标坐标不变，浮层和页面不溢出；审计有名称、未知身份和未知动作回退；Key 操作不越出单元格，全部动作的权限与确认继续生效；大纲可键盘使用，资料未保存值保留。截图避开 Key 明文。沿用 Vitest、Playwright 和项目 evidence runner，保持原服务进程与数据。
