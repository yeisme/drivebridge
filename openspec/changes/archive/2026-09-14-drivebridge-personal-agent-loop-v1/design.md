## Context

采用本 owner 既有架构与测试工具，在当前 checkout 顺序实现；测试服务使用临时状态和独立回环端口。保留原有 Skill 工作区改动。

## Decisions

本机 OAuth 继续由 rclone 持有，按用户选择的目录发现内部身份；不引入未验证的设备码流程。通用产物复用 upload，来源标签只是声明，不替代身份。固定版本引用必须解析所选版本。客户端只消费服务合同，领域任务、审核与费用仍归原 owner。

本地引用不承诺历史字节快照；远程受管引用在版本保留期间可消费旧版本。源改变、越界、权限撤销、密文交接不支持均明确失败。远程无等价 mkdir/changes/purge 时返回 unsupported，本机 state 仍为单进程独占，已有 Server 用于跨环境使用。

接口和存储只增量添加可选字段。未提供来源的旧请求保持原指纹；旧数据库迁移只加列。回滚保留新增列、文件、回执、实例身份和密钥；不执行删除式迁移。新增客户端能力遇到旧服务明确报错，不静默降级到错误版本。

## Verification

复用现有 Go 单元/fixture/testscript、真实进程 CLI/MCP 和 Web Vitest/Playwright。运行证据由 owner runner 生成并脱敏，任务完成状态只能通过既有 openspec-tasks 脚本写入。本机三场景、远程限定授权、旧版本来源、重放、错误恢复与网页交互分别验证；真实账号另验。
