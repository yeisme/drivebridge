# DriveBridge 紧凑工作区与可读性改进

## Why

两轮浏览器反馈显示：管理中心层级过深，控件尺寸不一致，表格和表单贴边，深色表格分隔线过亮，容量图表溢出，网盘入口缺少列表详情模式，分栏与画廊不利于阅读文件。目标是统一尺寸和信息结构，同时保留内容留白、全部原有能力和真实权限边界。

## What Changes

- 统一桌面控件为 32px；业务表格最低行高从初稿的 40px 修订为 48px，单元格上下至少 8px、左右至少 12px，明确控件高度不等于表格行高。
- 表单标签、输入框、说明和操作区分层；深浅主题使用语义边框，键盘焦点与普通分隔线分开。
- 管理中心迁入独立页面，五个分类可以深链接；创建和修改通过 480px 抽屉，团队成员与网盘管理复用团队页。
- Finder 合并新建入口、按内容宽度收纳筛选，移除位置描述行，把专注入口放到视图切换旁。
- 网盘目录与团队目录新增列表详情模式，保留卡片模式；用户目录继续使用已有表格与详情，不复制账号管理能力。
- 修复分栏文件名与画廊缩略项布局，提供明确的完整阅读入口，四种视图共享选择、固定版本及权限语义。
- 容量图按内容宽度排版，区分零与未采集；资源概览使用紧凑指标及列表。
- 为两轮十条反馈建立需求、实现任务与验收场景映射；保留未完成状态和失败证据。

## Capabilities

### New Capabilities

无。扩展已有客户端能力，不新建相近名称的能力域。

### Modified Capabilities

- `visual-craft`：语义令牌来源、控件与内容留白、表格边框和表单操作区。
- `client-shell`：管理中心路由、原入口兼容和上下文导航。
- `tenant-governance-web`：独立管理页、按需表单、明确执行及上下文切换。
- `user-directory-ui`：操作弹层与独立管理页适配，用户目录可读性。
- `green-workspace`：网盘列表详情模式及紧凑、真实的资源概览。
- `team-ui`：团队列表详情模式、权限矩阵留白和单一分页归属。
- `finder-file-actions`：统一工具栏、响应式收纳及专注入口。
- `finder-media-preview`：分栏与画廊阅读可达性。
- `insight-charts`：容器响应式、零值图表和结构化快照。

## Impact

归属判定为 `fit`：全部能力归本 client owner，包含服务端网页及共享组件的本机 view 消费者。服务端仍拥有治理、存储、传输、审计、固定版本与访问权限；本次不要求后端或 MCP 增加接口，不引入依赖、不改变数据库。

增量前端 hash 参数与可选组件参数向后兼容；原团队、文件、分享、用户及 Key 链接继续有效。`drivebridge-shadcn-full-ui-v1` 已提供原语基础；本 change 修正其调用和布局，归档时先收口该前置 change，再合入本 change，不重写其历史任务和证据。

本地实现与浏览器验收已完成并归档；证据见 [验收记录](../../../../docs/web/ui/compact-workspace-validation.md)。本轮不包含推送、发布、生产部署或真实账号操作。
