## Decisions

目录默认每页 50 条，平台管理员读取既有全局用户范围；租户管理员读取当前租户成员，其他用户读取本人及共享团队内用户。筛选包括状态、角色、团队、用户/Key 名称与标识。Key 名称/标识/有效期元数据仅本人或平台管理员可见，其他人得到 null 数量而不是零；不返回明文、哈希或密文。

账号全局冻结与归档仅平台管理员可操作且不能为本人。保留现有 verifyProof 验证；新写接口还要求确认和 expected_revision。事务内重新校验权限、版本和角色交接。影响接口返回会话、Key、Agent、个人网盘及文件数量和阻塞原因。归档是逻辑删除：保留身份、成员关系、文件和审计，停用用户并吊销 Key/Agent/分享，取消临时授权；恢复只回到冻结状态，不复活凭据与授权。解冻仅允许重新登录，不恢复旧会话。

冻结/归档检查所有租户的最后管理员、最后团队管理员和最后空间负责人；后继必须是未冻结用户。旧 account-status 复用同一事务，旧团队权限移除也不计入被冻结后继。

## Compatibility and rollback

User.archived 默认 false、revision 默认 1，GORM 增量迁移不移除旧字段。旧状态操作保留入口但不能绕过归档恢复与负责人保护；这是必要的权限一致性修复。旧 hash 登录与 Key 签发合同保持。回滚可撤回新 UI 与接口，但必须保留归档账号的 disabled 状态，不通过旧启用入口取消归档；无需删除新列。

## Validation

Go 测试覆盖筛选/元数据无泄露、不可见账号、冻结会话失效、归档文件保留、显式恢复、旧接口保护、失效的再次认证与 409。Playwright 在 client owner 覆盖完整账号流程。每次测试由 scripts/check.py 保存通过或失败证据。
