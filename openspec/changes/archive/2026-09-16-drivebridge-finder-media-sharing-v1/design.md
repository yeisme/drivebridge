# 设计与兼容

采用已确认的 Finder 布局，默认进入我的文件；本机与服务端共用 Finder、Media 和 Creator 组件。新增 API 使用独立路径，旧下载、上传、版本与授权操作继续兼容。当前治理入口按另一条 owner change 的权限投影工作，不覆盖其规则。

真实目录、离线索引、转换预览和固定版本引用分别如实呈现。列表分页，预览请求可取消；凭据不进入 localStorage。图像、视频、分享与引用的小图在访问授权后读取。专业格式依赖真实转换组件，缺失时保留原文件入口。

关键验证覆盖旧版本内容、多选与拖拽、上传中断恢复、匿名分享撤销、跨用户拒绝、显式 @ 素材、移动端溢出。本机测试复用实际 CLI 和私有 socket，在线生成使用模拟 owner，不运行付费服务。

回滚使用旧客户端资产，保留服务端新增状态；不删除用户文件、版本、分享记录或凭据。具体使用与运行限制见 docs/finder-media-creative.md。
