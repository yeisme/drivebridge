## Context

个人网盘、团队网盘共用 Finder，本机网页也复用该组件。CreatorPanel 仅由两个网页入口挂载。

## Goals / Non-Goals

删除全部网盘创作入口、面板及专用样式。保留正常预览转换、上传与分享。此次不变更领域服务 API，也不清理服务器上的既有任务或连接。

## Decisions

直接删除组件及调用状态，避免隐藏按钮后遗留可达面板。不增加开关或依赖。复用现有 Playwright 文件完整流程，分别在空目录和选择文件后断言入口不存在，同时继续验证上传、图片预览、分享和撤销。

## Risks / Trade-offs

网页不再能够创建生成任务；这是用户明确要求的产品范围调整。共享组件删除回调后通过 TypeScript 构建检查全部调用方。历史归档保持不变，更新当前规范描述。
