# 阅读与安全边界

PDF 使用锁定的 pdfjs-dist 6.3.289，React.lazy 加载，worker 与解析器同版本。字体、CMap 和 WASM 资源随 Vite 构建部署，同源加载；不接入 CDN。当前页单画布加 text layer，切页取消渲染，文件切换销毁 loading task。支持翻页、页码、缩放、适应宽度/整页、密码、权限错误、损坏、超时及重试。只渲染当前页，不激活文档脚本、XFA 或链接行为。下载沿用父检查器及服务端能力合同。

HTML 默认安全预览禁用脚本，保留文件 CSS 动画；交互模式仅在受支持的同源版本媒体 URL 开启 allow-scripts，不授予 allow-same-origin。读取文本上限 2 MiB，源码/交互共享缓存，不改变原文件。适应宽度使用可用舞台宽度，实际大小采用 1024px 参考视口并允许横向滚动。禁用外部网络与设备能力，不声称恢复原站 API。文件内脚本异常不能影响父工作区。

复合按钮延续 Button layout=surface，名称与树节点左对齐；图标与文件类型文字分别控制显隐。窄屏保留检查器抽屉和退出预览焦点恢复。

测试使用现有 Playwright、Vitest，PDF 样本由脚本生成，不含用户文件或凭据；检查真实像素与文字，覆盖密码、损坏、权限、中文、扫描件和移动端。依赖回退可恢复原阅读器代码，但不回退服务端沙箱和授权规则。
