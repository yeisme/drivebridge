1. **统一运行拓扑**：现有选型图偏个人工作台 HTTP 路径，应补齐本机 CLI/MCP、远程个人空间、HTTP 字节传输与创作 owner 的边界，明确同仓不等于共用物理数据库或同一进程。

3. **部署与故障模型**：补充个人单机默认拓扑、状态目录/字节/密钥备份关系，以及数据库提交与外部存储副作用之间的恢复边界。只设计，不启动服务或操作真实数据。
4. **原型证据可达性**：逐一校验 v39 资源摘要、截图和链接；保留冻结版本，不自动抓取新的远端快照扩大范围。已有页面截图不替代异常状态和全尺寸矩阵。
5. **文档一致性**：验收矩阵 AC29/AC30 与前表之间有空行，可能影响 Markdown 表格呈现；需要修正文档而非改业务。进一步检查任务引用、前后端依赖与不存在的命令标记。
6. **安全表述差异**：根 README 保留“任何 secret 永不入文件”的旧配置表述，当前 owner 规则允许用户级本地秘密配置。另有 public share/purge 的历史入口说明，而本任务不得启用公共分享或永久删除。设计需明确当前安全边界，不因历史文档放宽授权，也不在本轮改凭据持久化实现。
