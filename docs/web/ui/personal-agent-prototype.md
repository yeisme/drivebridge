## v9.2 交互与页面

- **单元格**：单击只选中；双击／Enter 显示单元格旁的非模态浮层，最多 320px 宽、正文最多 240px 高。短文本自然收紧，长文本可选择并滚动。Ctrl/Cmd+C 复制当前单元格，原生输入框和文字选择优先；失败提供手动复制。手机选中后显示“查看内容”图标。Escape 回到原单元格；滚动、换页、工作表和版本变化关闭浮层。移动到屏外单元格后先完成定位再展开，避免定位滚动误关闭。
- **文件类页面**：知识库、资源库、收藏与集合内文件复用 `FileDetailsList`；名称、列、排序与操作位置统一。文档、资源默认鼠标 36px／紧凑 32px，触屏至少 48px；表格仍保留 v9.1 的 28px／24px 与触屏 44px。文件名截断，完整信息由悬停和详情提供，星标和操作固定占位。单个列表中不会重复展示大图标、Provider 和多行标签。
- **知识库**：名称、目录、修改时间、标签与引用数按宽度呈现；编辑图标在悬停或键盘聚焦显示，触屏直接可见。收藏筛选使用用户＋空间＋连接收藏记录。手机将筛选和视图集中到“文档视图”，页码与选择仍直接可达。每页最多 50 项，选择范围与预览来源绑定当前页；预览返回保留页码、查询、筛选和焦点。属性表格与关系图入口仍保留。
- **资源库**：名称、类型、版本、检查状态和更新时间为明细列；筛选编辑使用草稿，取消不生效。选中后复用原位 44px 批量工具条；资料包不冒充文件参与批量选择。资源说明、包内文件、校验、字段、版本及使用记录进入右侧详情；保存不等于检查、安装或执行。资料包继续使用原集合身份及固定上下文。
- **任务、收件、分享与连接**：概览使用 48px 状态行，触屏至少 56px，显示名称、状态和简要来源；完整文件引用、权限说明、确认、回查、恢复与验收在详情中完成。单文件任务标题和收件文件名仍可直接进入固定引用预览。原任务编号和操作回执保持不变。
- **其他页面**：集合索引默认列表，封面／图库按需开启；首页保留小型精选预览，最近文件使用明细。设备、规则、索引与调用记录统一状态行；协作的共享和邀请保留详情操作；标签、属性、设置与能力说明压缩标题、间距和字段分组，正文及重要限制保留合理阅读宽度。
- **弹层与反馈**：原型 `DialogContent` 增加确认 400px、简单表单 520px、复杂表单 640px、右侧长详情四种用途。完整文本与复制回退使用可选择文字，避免只读大文本框。移除多层焦点描边与普通行阴影，保留键盘焦点、错误、范围、权限与不可逆操作说明。
- **样本与偏好**：顶栏演示入口可添加 120 份文档与 60 份资源分页样本，同一空间重复点击不重复生成，重置可清除。只证明原型分页和界面状态，不代表真实 Provider 性能。没有新增领域状态本地持久化。

## v9.1 预览交互

- **工作区**：应用顶栏 48px＋文件工具条 44px；取消左侧说明底栏、底部详情和独立缩放栏。文件工具条提供阅读设置；够宽时直接显示阅读控制，窄屏收进同一阅读设置浮层。Markdown 继续使用同一工具条和既有编辑会话。音视频控制覆盖在媒体画面内，切换文件暂停旧播放，新文件不自动播放。
- **右侧详情**：每次进入工作台默认关闭。打开后为页面内 320px 右侧浮层，不加全页遮罩、不挤压正文；桌面点击正文保持面板。实际页面宽度至少 1100px 才允许固定，固定后正文至少 440px。变窄自动覆盖、恢复宽度重新固定；偏好不丢失。手机为工具条下方的完整右侧面板，关闭回到入口，Escape 先关闭当前弹窗，再收起详情，下一次才退出工作台。
- **详情连续性**：详情、讨论、版本、活动、关联继续保留；标题与栏目固定，内容单独滚动。详情模式、栏目与文件清单显隐不重建正文。栏目和滚动按用户、空间、文件保存；评论草稿按用户、空间、固定文件版本保存，切换栏目或文件不丢失，均不写入偏好存储。
- **紧凑清单**：默认 220px，鼠标拖动或分隔线方向键可调整 200–320px，双击恢复。鼠标行高 36px／紧凑 32px、图标 16px，触屏行高至少 44px。单行文件名＋版本，完整路径、大小、Provider 和异常说明由悬停／详情提供。多目录以相邻路径分组，保持来源引用原顺序；不遍历整盘。来源、数量与搜索集中在顶部；不足 760px 时通过文件列表入口打开左侧选择面板。
- **精细只读表格**：移除大卡片与重复标题，正文四周 8px，默认单元格 12px 字体，鼠标行高 28px／紧凑 24px，触屏可操作行至少 44px。行号、固定表头、轻网格线、数值右对齐和当前单元格状态；默认列宽 144／104／96／240px，不拉伸填满屏幕。列分隔线支持拖动、方向键与恢复，横向滚动只发生在网格内。
- **表格交互**：点击或 Enter 查看完整只读文本并复制；剪贴板失败保留手动复制入口。方向键在当前页单元格移动。阅读设置含工作表、查找、页码和恢复列宽，每页最多挂载 50 行。按用户、空间、文件、版本、工作表分别保留页码、查找、滚动、列宽与当前单元格；切换详情不重置。
- **演示边界**：表格包含多工作表、长文本、多列、千行分页与空表样本；加载／读取失败可在阅读设置中切换与恢复，版本不可用沿用统一固定引用检查。样本不解析真实工作簿，不执行宏、公式或脚本，不代表真实文件性能。
- **偏好兼容**：旧 `bottom` 映射为覆盖模式（私有值 `auto`）；旧 `right` 保留固定偏好，窄屏回退覆盖；旧清单宽度限制在 200–320px。首次详情仍关闭，不根据固定偏好自动打开。

## v9 历史规则与验证

继续更新原 Open Design 项目；本轮以以下规则替换 v8 的目录列表、目录检索跳转、居中空间弹窗和即时生效筛选。原始目录、按连接收藏、Markdown 属性、连续预览、外部 MCP/API 与产物验收保留，不恢复内置 Agent。

## v9 浏览与交互

- **资源栏**：默认 220px，可用鼠标、键盘分隔线调整至 200–320px，双击恢复。可用工作区不足 760px 时通过“目录”打开选择面板。目录／标签／属性各自保留查找、展开与滚动状态；不会在应用顶部再加一组导航。
- **目录树**：鼠标行高 32px、图标 16px、缩进 12px；触屏行与展开按钮至少 44px。已知叶节点无展开箭头，不重复显示“无子目录”。未知、加载、部分加载、失败、失权和断连各自反馈。收藏与置顶引用只在对应连接展开时显示。树内查找只查已加载目录；“定位当前目录”和“收起其他连接”不扫描全盘。
- **标签／属性树**：标签以 `/` 建层级，名称／频次排序，父标签默认包含后代，可在生效条件中切换精确匹配。属性依显示分组、字段和值组织，支持文本／列表、布尔、日期／数字范围；未设置、空值、类型异常、未提取、解析失败和过期状态独立呈现。常用值每次加载 20 项；计数来自当前目录及明确后代范围的授权样本，不是完整网盘聚合。
- **紧凑明细**：目录和文件共用明细表，文件夹优先，文件沿用名称／大小／更新时间排序；表头支持升降序，窄屏排序放入目录更多菜单。鼠标默认 36px、紧凑 32px，触屏至少 48px；手机两行展示。列按实际可用宽度隐藏，来源与路径在检索中展示，同盘日常浏览不重复堆叠 Provider。文件少时不拉高行。50 条分页，勾选和星标固定占位，批量栏原位保持 44px。
- **导航语义**：后退／前进沿当前用户、空间内的目录、收藏和查询记录移动，可以跨连接。上一级只进入物理父目录，根禁用。检索时提供“返回目录”，恢复来源目录的排序、分页、滚动与焦点。面包屑可点击祖先，深路径中间层收进菜单；窄屏将前进、历史、刷新、复制路径等放入“目录更多操作”。新位置清除前进分支，失权时保留原位置说明原因，不匹配同名替代目标。

## v8 当前交互规格

### 按连接收藏

- 云盘每个连接根节点提供“本盘收藏”；当前连接最多显示五个置顶引用，其余进入收藏页。文件、目录、当前目录工具条、文件详情及检索结果均可收藏。单击加入未分组，通知提供“选择收藏夹”，不强制弹窗。
- 收藏页支持全部、未分组和单层自建收藏夹；条目可加入多个组。组管理支持改名、删除、组内移除与取消全部收藏；置顶支持调整顺序。删除分组保留条目，取消收藏不删除原文件。
- 收藏目录打开物理目录，并提供返回收藏夹；文件进入原预览工作台，继续保留来源清单、固定版本引用、400ms 悬停和返回位置。收藏自身跟随当前可访问版本，固定交付仍使用原有分享流程。
- 稳定身份由 space、connectionId、rootId、kind、id 组成，不按路径或同名条目合并。受管文件重命名后更新显示；S3 对象／前缀变化标记“需重新定位”。断连、撤权、删除或根范围变化保留用户已知的收藏记录，不揭示新的受限内容。
- 收藏、文件内 favorite 属性、源 Provider 星标是三个独立概念。同类两个账号互不混用分组。旧样本星标迁为当前演示用户收藏；不迁移生产 Finder 的 localStorage 数据。

### 文档属性、标签与 Skill 字段

- 文件操作提供“文件属性”，进入已有详情分区。属性不增加顶部工具条行，也不在文档上方常驻大型表单。系统名称、目录、Provider、权限、大小与版本仍由原文件操作管理。
- Markdown 属性和源码共用一个草稿、CodeMirror 编辑历史与保存状态。属性字段失焦／Enter 后写入草稿，继续使用 800ms 空闲自动保存、手动保存与冲突处理。表格和详情只改目标字段；CodeMirror 用最小文本事务同步，切换模式不会重建编辑器。
- `yaml` 2.9.1 解析节点和源码范围，补丁保留正文、未知字段、未修改注释及换行。源码显示完整文首；实时编辑和阅读不把 YAML 当正文排版。支持文本、文本列表、数字、复选框、日期和日期时间；单／多选建议分别保存为文本／列表。
- 复杂嵌套、锚点或引用先只读，链接至源码。无效 YAML、重复键与未闭合文首阻止表单写入，但源码仍可编辑、保存；解析失败不等同于空属性。类型不一致展示原值，不能静默转换。
- 文首 tags、正文 #标签、平台人工／规则标签与外部建议区分来源；正式筛选不含待接受建议。支持层级父标签包含子标签及“仅此标签”。提取器忽略代码块、行内代码、标题标记与链接中的标签片段。
- 文档标签默认写入 YAML tags；正文标签提供源码位置。平台标签只有明确点击“写入文档标签”后才进入文件。合并文首标签先展示差异与受影响文件，正文标签保持原文，不因删除或合并文首值而改写正文。
- “标签与属性”提供空间字段定义、显示名称、分组、类型、建议选项和异常入口。字段键迁移、类型转换及标签合并生成固定版本计划；部分失败保留原操作，只恢复未完成项。无法安全转换或目标键已有值时跳过，保留原文。定义和保存视图仅在完整迁移后更新；部分迁移提示逐项检查。
- Skill 字段表单现在读写同一份 frontmatter，修改清除旧检查结果；未知字段保留。检查通过仍只表示演示结构／依赖检查，不表示安装或执行。

### 快速查找、属性表格与索引

- Ctrl/Cmd+K 空输入显示当前连接的置顶、最近访问和收藏；名称检索同时返回文件和目录。250ms 空闲后查询，Enter 立即执行，中文组合期间不提交；范围代次阻止旧候选覆盖新范围。
- 默认当前连接；目录搜索保留目录及后代／仅本层规则。跨连接必须在完整检索页明确选择。排序为名称完全匹配、前缀、名称关键词、路径；收藏与最近访问仅作同类排序依据，当前结果打星不会突然换位。
- 检索提供仅收藏、指定收藏夹、在收藏目录内检索、文档层级标签和属性条件。收藏目录不等于收藏所有后代。结果说明来源是个人收藏、已加载目录或目录索引，并标明连接、路径、版本与命中原因；正文检索仍独立授权。
- 云盘、知识库与检索复用属性表格。支持选列、列宽、顺序、固定名称列、排序、项目／状态／日期／标签等分组。分组标题常驻，不使用正文手风琴；多值分组可重复展示条目，总数按文件去重。当前页分组不伪装成全盘统计。
- 属性条件区分相等、不等、包含、属于列表、范围、空值和未设置；0、false、空文本、null、未解析、类型错误与过期投影分别处理。编辑后保留当前结果行与焦点，下一次明确查询时重新匹配；分组与排序通过“刷新分组”更新。保存视图记录连接、目录、条件、列、分组及排序；跨连接视图只作为检索视图。

- 输入停止 800ms 后开始保存，保存反馈阶段为 120ms；Ctrl/Cmd+S 立即保存。中文输入法组合期间停止自动保存与块重排。相同正文不新增版本。
- 草稿按文件保留，阅读位置按文件与版本保留；切换详情、Agent、模式或来源会话不会删除草稿。刷新恢复样本，未保存内容使用离开提醒；正文、Skill 字段、授权与会话不写入 localStorage。
- 保存检查基准版本、权限和连接写入能力。失败、离线、冲突保留草稿，提供重试、差异、另存副本和确认重新载入。已加载文档在离线时仍可继续编辑，联网后恢复保存。历史版本只读，主动进入最新版本才能编辑。固定版本引用始终显示已保存正文，不混入同文件的未保存草稿；从引用返回恢复先前的编辑或草稿阅读状态。
- 演示与审阅弹窗补充“暂停／恢复文档自动保存、模拟下次保存失败、模拟文档并发修改”。这些控制默认收起。

### 双链与附件

- 支持 Wikilink、标题、显示名称和普通 Markdown 内部链接。候选显示目录与连接，同名条目以完整位置消歧；代码块与行内代码不产生关系。未知语法保留源码。
- 渲染后的链接与附件复用 400ms 悬停、直接点击和统一权限检查；新引用建立独立预览来源会话，返回恢复原文档，不把链接目标追加到原有有序清单。
- 页面详情增加“关联”，固定展示出链、反链、未关联提及、附件。反链有上下文片段；未关联提及需确认才能修改源文档。缺失、失权、歧义及标题不存在明确反馈。
- 关系页提供文档、附件、标签的一跳分支视图及列表切换，显示当前授权与已解析范围。此处是有边界的演示投影，不是客户端生产索引。
- 重命名与移动先冻结影响清单及版本，再确认更新引用；新草稿、版本漂移、权限变化或目标冲突均阻止应用。
- 拖入文件、粘贴图片或选择设备文件只模拟附件传输与文件记录，不读取或上传真实字节。已有附件可以直接嵌入。失败占位不变成有效引用，恢复沿用原任务；取消和迟到完成不能重新生成附件。
- 附件页显示来源、版本和反向引用；删除先展示已扫描范围内的影响，再进入原回收站计划。未找到反链不能证明全空间没有引用。

### Agent 资源与回存

资源列表支持类型、名称、标签、来源、更新时间和检查状态筛选；资料包复用集合，使用时冻结当前文件版本。示例 Skill 资源包包含 SKILL.md、references、scripts 和 assets，脚本展示源码但不执行。

资源详情包含说明、文件、版本、使用记录，展示作者声明、来源、依赖、输入输出及检查时间。结构化字段通过表单修改并保留未知字段；修改正文或字段生成新版本并使检查失效。状态区分已存储、待检查、检查通过、缺少依赖及不可用；检查仅匹配演示能力列表，不证明真实运行环境可用。

Agent 输入区上方区分参考资料与本次 Skill。未保存正文先保存再固定引用；选区引用保留选定文本及文件版本。双链、附件与 Skill 内文不会自动扩权。生成摘要和修改正文均冻结输入、Skill 版本与计划；修改显示前后正文，确认后新增版本。新产物进入收件箱，保存输入引用、来源任务、Skill 版本及验收去向。

重复确认不重复执行；版本与权限变化使旧计划失效。重新预览沿用原任务并提升计划修订，旧修订不能确认。结果未知时查询原操作，不重提任务。任务和收件箱继续支持固定版本预览、接收、归档与退回。

## v3 交互规格（保留依据，冲突时以 v5 为准）

本轮组件结构为：双端壳层 → 我的云盘／标签／搜索／设置／连接 → 固定 Agent 宿主；文件列表、集合和搜索共用固定高度的工具条，手机共用原底部导航区域。既有操作计划、版本、收件和恢复仍使用原状态模型。本轮只扩展原型，不引入生产 API、领域索引或真实连接。

### 批量操作与日常界面

桌面把原“数量／选择”行固定为 44px。选中时原位换成“已选、标签、移动、分享、交给 Agent、更多、取消”，根据容器宽度收纳操作，不换行、不新增行。列表、网格、集合和搜索结果遵循相同规则。手机原位替换底部导航，保留原高度和安全区。多选不会自动展开 Agent；搜索条件或目录变化清空选择，分页保留。提示复用顶部已有审阅栏，不推移文件区。Escape 先关闭当前菜单或弹窗，再退出多选。

### 云盘与 Agent 布局

默认进入“我的云盘”的列表视图，首页和创作项目集合保留。手机压缩工具区，目录采用横向单行；排序进入筛选面板，尽量让文件尽早进入视口。标签固定单行显示两个和“＋N”。

Agent 默认收起，顶栏与手机“助手”打开同一宿主。1280px 及以上为 360px 固定侧栏，可用分隔条或键盘在 320–480px 调整；768–1279px 为右侧覆盖抽屉；手机为完整右侧面板，遵循可视视口高度。没有独立桌面助手页面或拖动悬浮窗。关闭恢复文件页面、滚动和入口焦点。会话、草稿、固定引用、任务和检索共用原有状态，目录切换不扩大上下文。

### 标签与检索

标签采用空间内目录、分组和多项分配；人工、规则、Agent 建议独立，默认追加人工标签，替换另行确认。合并、删除展示影响文件和视图，更新引用但不移动或删除文件。标签筛选支持全部、任意、排除；建议未接受前不参与普通标签匹配。分组和颜色属于交互设计，当前生产服务仍使用标签字符串及 namespace，不把原型 ID 当作生产协议。

搜索分文件、内容、标签、设置。普通搜索不依赖内容分析，默认当前空间的主云盘，跨连接显式选择。Agent 先把样本自然语言转成可编辑条件，用户确认后执行；它不是已接入的自然语言解析服务。内容索引必须明确授权目录、类型、排除项、处理位置与费用；排队、处理中、部分失败、暂停、可用及过期均可演示。结果固定文件版本，标出片段、覆盖限制与观测时间。历史或过期引用用于预览，不能静默升级成最新版本参与修改。

## 产品结构与视觉规格

- 桌面：208px 主导航；768–1199px 收窄为 64px 图标导航；低于 768px 使用手机布局。64px 顶栏保持文件搜索和任务通知；素材库在至少 1200px 时按需打开助手侧栏，图库模式优先保留素材空间。

- 沿用 Precision Pine 绿色主操作、状态色、中文系统字体和 Lucide；大面积使用浅灰白背景、白色内容面和细边框。插画缩略图由本地 SVG 绘制，图片、影片、文档和音频有不同视觉表达，并标注为示例内容；没有外部素材或付费出图调用。
- 素材库支持列表、网格与大图，显示版本、标签、来源、位置和选中态。助手侧栏默认收起；会话页面区分「梳理资料 / 找素材 / 整理文件」，上下文默认折叠为摘要，需要时展开。
- 任务默认显示紧凑摘要、阶段与主操作，逐项详情按需展开；进度由完成项计算，避免用固定百分比暗示真实传输。较长计划、历史修订和恢复记录放在详情中。
- 触屏操作目标至少 44px；支持 Tab、Space、Enter、Escape、命令搜索快捷键、明显焦点和返回焦点。长按文件进入选择，Shift 点击连续选择，文件区域支持 Ctrl/Cmd+A 选择当前页；跨页全选另行确认。拖入文件打开模拟采集。
- 减少动效时停止加载旋转及过渡；截图等待字体和有限动画完成。提示保留在正常布局中，避免遮挡底部动作。长名称、会话与版本引用允许换行或提供完整名称。

组件关系为：演示控制 → 双端壳层 → 文件/助手/任务等页面 → 统一弹窗；所有页面通过同一纯状态转换函数处理文件引用、任务与结果。界面控件复用现有 `Button`、`Input`、`Textarea`、`Checkbox`、`Select`、`Dialog`。

## 核心交互与控制规则

| 控件 / 行为 | 结果、失败与恢复 |
| --- | --- |
| 页面、空间与设备切换 | 页面切换保留同一任务；空间切换清空选择，载入该空间的独立会话；另一空间的消息不显示，迟到结果不得进入新空间或清除新会话的等待状态；设备按钮只改变同页呈现 |
| 文件列表、搜索与筛选 | 只显示当前空间；名称、类型、来源、标签与更新时间可组合；目录导航独立于助手范围；分页选择与选择全部匹配结果分开；空结果可清除筛选 |
| 收藏、多选、标签 | 明确选中态；人工确认更新标签；不会因模型建议覆盖人工标签 |
| 助手发送与上下文移除 | 未授权的内容分析先展示范围/位置/费用；更换上下文或版本需要重新确认；已有引用保持原版本，草稿与历史消息保留；取消分析不丢失草稿；pending 防止重复提交 |
| 引用与版本选择 | 打开被引用的固定版本；历史版本提示明显，旧评论不迁移到新版本 |
| 检查计划与确认 | 只对所见版本有效；已确认、过期、失权不能再次执行；调整目录、名称或包含项生成新修订；已完成项保持原结果；跨存储发送、覆盖和回收站动作分别确认 |
| 暂停、恢复、取消 | 继续原操作并跳过完成项；取消保留已发生修改；未知结果应回读原操作；不会更换来源、目标或任务身份 |
| 恢复计划 | 由完成项派生反向计划；原文件已有后续修改则拒绝自动回退 |
| Agent 接入 / 撤销 | 复制无凭据说明，单独验证连接；撤销停止未完成任务；重新授权后需重新预览，不能自动续跑；新授权目录不覆盖旧任务时拒绝继续 |
| 产物接收、改位置、退回 | 上传验证完成后才可归档；明确选择目录；退回移入回收站，可恢复 |
| 固定交付与撤销 | 清单校验后单独确认；固定版本不跟随最新版；撤销仅阻止后续访问，不宣称召回下载副本 |
| 备份 / 同步规则 | 备份创建副本并保留源文件；同步只演示新增副本，不传播删除；整理才移动文件 |
| 原生入口 | 相册、拍照、系统分享、本机打开、配对与通知均明确标为模拟或待客户端集成，无浏览器越权读盘 |
| 模态框与通知 | Escape 可关闭、焦点回到入口；消息反馈留在布局内，不遮挡操作；所有不可执行入口有解释 |

查询与建议可在现有 read 范围内直接进行；标签/集合需本次确认或预授权；移动等先出计划；覆盖、软删除、外发和权限改变分别确认；永久删除和凭据管理不进入自主整理面。文件内容、模型回答和相似度均不能提供操作权限。

## 客户端接入顺序

1. 先接素材列表、文件/版本预览、虚拟集合和文件查询，保留现有 Server 文件真源。集合、列表偏好与消息草稿不能代替权限合同。
2. 再接助手会话、分析同意、固定引用、原计划确认和任务投影；读取和建议可直接进行，修改仍走 DriveBridge 的分级授权。
3. 接收件、版本比较和多文件交付；输入引用、输出版本和接收事实分别记录，不以接收代替领域验收。
4. 原生宿主随后提供本机打开、拖放、系统分享、相册/目录授权、托盘、通知深链和受控离线缓存；备份/同步从公开能力查询降级。当前没有选定或实现原生框架，也没有把 Web 模拟状态宣称为真实设备状态。

## 最小接口交接

以下是需要实现团队对齐的能力语义，不是新增的已上线 wire API；不得把原型 `model.ts` 直接当作生产协议。

| 交互合同 | 必需内容 | 真源与约束 |
| --- | --- | --- |
| AssistantSession / 消息 | 空间、会话 ID/标题、草稿、分析同意、消息、固定 file/version 引用、关联原操作与迟到结果锚点 | 服务端文件助手门面；内容理解消费 Manju 等公开合同；客户端不持有 provider 凭据 |
| CollectionProjection | 集合 ID、空间、文件引用或查询条件、参考/工作稿/交付分组 | Server 组织合同；集合不改变文件原位置，不扩大权限 |
| VersionComparison | 左右文件/版本、内容快照、恢复目标版本 | Server 提供受权的版本内容；恢复新增版本、保留历史 |
| AgentTaskProjection | 原 owner/任务/操作标识、阶段、逐项结果、等待原因、产物引用 | 聚合投影不替代原任务；上传已发送不等于已保存；领域采纳单独表达 |
| ApprovalRequest | 固定清单、修改前后、包含/跳过项、修订记录、risk、revision、impact digest、权限/策略版本 | 消费既有 organization plan 确认合同；人类决策与任务状态分离 |
| DeviceCapability / Continuation | 当前设备能力、已授权目录、任务/文件版本锚点、续接状态 | 配对不扩权；设备缺席/平台不支持如实展示；深链不得携带永久凭据 |
| OfflineAvailability | 文件版本、可用性、下载阶段、缓存大小/到期、云端观测时间 | 客户端受控缓存；Server 仍拥有文件版本与权限；旧副本明确标记 |
| SyncConflict | 原操作、双方版本、目标、冲突原因、允许的处理方式 | 事务 owner 复查权限与版本；不把客户端索引当作最新真相 |

正式接入优先复用现有 File/Version/Operation、upload-batches、file-queries、organization-plans、delivery、content-bindings 与 grants。保持现有状态枚举和路由兼容，新增投影通过 owner 合同演进。

## 平台与安全限制

移动后台任务必须按系统能力设计“等待网络”“等待系统恢复”“需重新打开应用”等状态。[Apple 后台传输说明](https://developer.apple.com/documentation/foundation/downloading-files-in-the-background)与 [Android 长任务说明](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/long-running)提供正式实现依据。模拟窗口切换不证明系统后台能力，浏览器离线模拟不证明原生安全缓存。

本原型没有 OAuth、登录、令牌签发、设备配对或外发；不会保存真实用户问题、文件内容或本机路径。截图仅包含虚构样本。正式原生实现需要独立验证存储加密、系统权限、通知、后台恢复、登出清理与撤权体验。本轮不创建新的领域 owner 或迁移 DriveBridge 既有仓库。
