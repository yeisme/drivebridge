# 表格预览

XLSX、CSV 与 TSV 使用独立表格阅读器。XLSX 可切换工作表；CSV/TSV 保留文本值，包括前导零、引号内分隔符与换行。CSV 支持自动识别或手动选择分隔符，中文乱码时可切换 UTF-8／GB18030 编码。表格提供行号、列标记和分页，宽表在阅读器内部滚动。

预览只读，不保存单元格修改，不执行公式、宏或单元格中的 HTML。XLSX 展示文件中已有的格式化值，不重新计算公式；缺少缓存值但保留公式的单元格显示公式文本。图表、图片、合并样式和打印版式不属于表格阅读器的还原范围。原文件下载继续使用既有下载入口和权限。

文件读取沿用带版本的媒体接口和本机文件投影。服务端继续校验文件访问权限、租户与版本；不把表格上传给第三方在线 Office 服务。解析在浏览器 Worker 中进行，文件切换时取消旧任务，超时或解析失败时显示错误与重试入口。

文件读取上限为 16 MiB，每张工作表最多预览 2000 行、100 列，每页显示 100 行，单元格文本最多显示 10000 个字符。达到上限时明确提示部分内容未显示，不把预览子集当作完整文件。读取与解析共用 30 秒超时；压缩工作簿解压仍可能消耗较多 Worker 内存，文件大小限制不等于解压后内存限制。解析依赖固定为 [SheetJS 官方分发](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)的 0.20.3 版本，并通过依赖锁文件校验。

相关回归覆盖解析、文件类型识别、服务端读取权限，以及本地 fixture 上传后的真实浏览器阅读。测试使用合成文件，不表示真实云账号或部署验收。
