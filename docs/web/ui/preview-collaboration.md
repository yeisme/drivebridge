# 文件预览与协作设计

## 本轮实现

预览窗口使用 92dvh，高度贯通内容容器，不再将 HTML 和图片挤在顶部 320px 区域。头部保留文件名、最大化、信息栏开关与关闭；底部仅保留前后文件导航。普通控件 40px，触控目标 44px。沿用 Precision Pine 色彩。

组件关系：预览对话框 → 头部控制 / 内容舞台 / 可折叠侧栏；舞台 → HTML、图片或既有媒体查看器；侧栏 → 文件搜索与类型筛选 / 当前文件信息 / 原有文件操作。

HTML 默认静态渲染；用户点击“交互预览”才在独立沙箱中执行文件内脚本，适用于自包含按钮、动画和图表。源码切换用于检查，重新运行清空该文档的临时状态。交互帧没有同源权限、弹窗、下载、顶层导航或表单提交许可；CSP 限制脚本、样式、媒体来源和网络请求。不能保证依赖 CDN、远程 API 或持久化存储的完整网页工作，也不宣称沙箱能阻止恶意脚本占用 CPU 或所有帧内导航。

交互模式使用服务端已有的版本固定媒体入口，添加 `preview=interactive`。默认静态响应不变。父应用的 CSP 继续禁止内联脚本；使用独立文档响应避免 srcdoc 继承父级 CSP 后脚本不能执行。服务端只允许小于等于 2 MiB 的 text/html 进入交互模式，并保留原有身份/版本/读权限校验。请求实际字节上限也在源码读取中校验。本机、外部预览 URL 未支持这一合同，界面禁用交互入口并说明原因。需要同时更新客户端与服务端，旧服务端不会自动获得交互能力。

图片编辑保留旋转、镜像、缩放与原始分辨率 PNG 导出；新增椭圆、文字、画布拖动、撤销/重做。颜色和线宽与形状工具分组；线宽与字号按屏幕大小换算到原图坐标。清空可以撤销，导出生成副本，不覆盖服务器原件。参考协作软件的常见批注分组，未宣称复刻飞书全部编辑能力；裁剪、马赛克、逐标注选择编辑不在本轮实现。

文件较多时可按名称/路径搜索、按媒体类型筛选、定位当前文件；每组最多 40 个，显示总数和分组导航。当前选择不会被搜索自动替换。仅覆盖本次 Finder 打开的文件集合，不冒充全盘检索。

## 评论与备注：后续能力，尚未实现

客户端承载协作体验（fit）；评论、备注、权限、版本锚点与审计归 DriveBridge Server（split-owner）。不使用 localStorage 冒充团队共享评论。服务端没有提供相应合同前，不显示可发送的评论输入框。

侧栏后续改为“文件 / 信息 / 讨论”三个入口。讨论页有“团队评论 / 我的备注”切换。文件导航在列表模式下占满侧栏可用高度，信息和讨论各自独立滚动；收起侧栏后主舞台获得全部宽度。

团队评论显示作者、时间、针对版本、正文与回复；线程可解决/重新打开。默认针对当前版本，新版本出现时保留旧版本标记并提供返回该版本入口，绝不静默把旧批注挂到新图片。第一批做文件级评论，第二批扩展图片归一化坐标与视频时间点；HTML 不允许任意 DOM 选择器或脚本成为可信锚点。

我的备注默认仅作者可见，与文件权限同时校验；用户显式操作后才能复制为团队评论。公开前预览目标团队和正文，不复用模糊的“保存”按钮。编辑、删除、解决状态由服务端持久化；删除保留审计占位，不泄露已撤销访问者的正文。

最小服务合同：按文件和版本分页读取线程，创建线程、回复、编辑本人正文、删除本人正文、解决/重新打开线程。创建采用幂等键；编辑采用版本并发检查；作者身份来自会话，不能接受客户端自报作者。网盘读权限决定可见性，评论写权限单独校验，成员离开或权限撤销立即停止读写。机器人发表使用自己的服务端身份并明确标记，不冒充人类。

输入首批仅支持纯文本，限制正文长度，换行正常展示；不渲染任意 HTML。失败时保留当前输入并提供重试，发送成功才清空。未发送草稿仅保留内存，切换文件或关闭前确认是否放弃。通知首批仅应用内，@成员与外部通知另行提供合同和授权。

验收应覆盖双用户实时/刷新可见、跨团队拒绝、仅本人备注、旧版本定位、重复请求、并发编辑、权限撤销、失败重试、正文 XSS、键盘与移动端。

## 机器人接入引导

用户界面统一称“机器人授权”，`agents` 路由、API 和协议名兼容保留。页面和一次性 token 展示页提供同一个接入引导。

流程：限定范围签发 → 私有保存 token → 选择远程 MCP 或本机 CLI → 复制配置模板 → 客户端连接验证。模板不含真实 token，浏览器不写本机配置文件，不以复制成功宣称连接成功。

远程 MCP：服务地址加 `/mcp`，Streamable HTTP，Authorization Bearer token；无需本机 CLI。用 tools/list 和 inputSchema 发现合同，再读取 capabilities。模板只是通用参考，外层 JSON 由客户端配置格式决定。

本机 CLI：通过 `drivebridge config set remote_url`、`remote_token_file`、`local_root` 配置，使用 `drivebridge space list --json` 验证，再运行 `drivebridge install --client generic --json` 输出注册信息。支持专用安装器的客户端可运行 `drivebridge install --client claude-code` 或 `drivebridge install --client codex`；这一步由用户在机器人设备上执行。token 文件必须仅本人可读，复制模板不接触真实凭据。localhost 仅适用于同机机器人，跨机器须使用可达服务地址。

后续“一键配置”应以已核验的客户端安装协议实现，并明确弹出即将写入的位置、作用域和是否覆盖现有条目；当前不虚构浏览器一键修改桌面配置能力。
