# 个人多 Agent 工作台 UI 规格

状态：部分实现，正在进行全站 Web 对齐；不能把历史待实现或单项通过当成全站结论。当前依据为 2026-10-07 经 Open Design MCP 确认并冻结的[全站差距基线](workspace-visual-gap-baseline.md)、[PRD](../product/personal-agent-workspace-prd.md) 与历史[原型证据](personal-workspace-reference.md)。本文件固定正式 UI 的补充规则；有明确数值的新增规则属于本次设计，不冒充原型已有实现。

## 1. 视觉与组件合同

沿用 Precision Pine：深松绿导航、浅中性工作面、密集文件列表、右侧详情。React 19/TypeScript/Vite/Tailwind 4、现有 Base UI/shadcn 原语、lucide、TanStack Table；继续使用 typed fetch。无需引入新框架、axios、第二套组件库或动效运行时。技术决策见 [D01–D07](../../architecture/personal-workspace-technical-decisions.md)：类型化 hash 路由表保旧深链，页面 state/reducer 与身份/壳层 Context，不引入全局文件 store 或自研查询缓存。

| Token / 区域 | 正式值或规则 |
| --- | --- |
| 主色 / hover | `--ui-primary: #245a45`；hover 用同一语义色阶 |

## 2. 壳层、路由和双端布局

桌面：184px 主导航 + 48px 顶栏 + 内容；收起为 56px icon rail。网盘内部使用约 220px 目录栏 + 文件主体 + 可选详情；内容区独立滚动，页面本身不出现双滚动条。导航长时中段滚动，底部容量/设置固定。

正式响应式规则：

- 320–767px：48px 顶栏、底部五栏（首页/文件/Agent/任务/我的），底部加 safe-area；主侧栏为抽屉，目录树独立抽屉，详情全宽。顶栏保留搜索、导航、用量、当前页与原传输恢复；隐藏重复的工作空间前缀，主题切换移入导航抽屉。连接指南/添加存储/签发等页面动作放在内容区，不能撑高全局顶栏。主要触控入口、抽屉/弹层关闭按钮至少44px。表格隐藏次要列或采用同数据的紧凑行，不能复制业务状态。
- 768–1279px：默认 icon rail；目录可覆盖式展开；详情浮层不挤压小于 480px 的主内容。
- ≥1280px：默认展开侧栏；只有主内容仍可保留 640px 时才允许详情固定。阈值按可用容器宽度裁决，不能只看设备型号。
- 详情设计默认宽度：文件 360px、任务/Agent 440px；可调整区间 320–640px，并裁到可用宽度。手机覆盖此偏好。侧栏/目录/详情不能同时将正文压到零。
- 拖拽分隔条用 separator 语义和 aria-valuemin/max/now；箭头 16px、Shift 32px、Home/End 极值、Enter/双击复位、Escape 取消本次拖拽。
- 窗口缩小只临时降级布局，不覆盖桌面偏好。偏好按实例/用户命名空间保存；登出清除身份数据，不能携带上一个人的目录或筛选。

| 分组 | 可见入口 | 正式 canonical route |
| --- | --- | --- |
| 工作台 | 我的工作台、我的云盘、知识库、资源库、项目集合、标签与属性、搜索、任务中心 | `#/home`、`#/files`、`#/knowledge`、`#/resources`、`#/collections`、`#/properties`、`#/search`、`#/tasks` |
| Agent | 产物与收件、Agent 管理 | `#/inbox`、`#/agents` |
| 管理 | 存储管理、设备与离线、备份与整理、回收站、能力与连接说明 | `#/storage`、`#/devices`、`#/automation`、`#/trash`、`#/capabilities` |
| 底部 / 按权限 | 个人设置、分享管理、既有团队/治理入口 | `#/settings`、`#/shares` 与保留旧深链 |

空间、连接、目录、file_id/version_id、owner_task_ref、查询/排序/页游标有显式 URL 解析。URL 不含正文、token 或临时 URL。复杂/敏感搜索只保留会话内状态；分享深链仅含稳定资源标识，进入后重新鉴权。旧路由映射见重建文档，不复用旧 URL 表达不同功能。

主导航文案统一为“我的工作台／任务中心／Agent 管理／存储管理”；内部 `overview/transfers/agents/connections` ID 不改。文件入口沿用“我的网盘”（与产品叙述“我的云盘”同义），旧团队表单的“存储连接”、旧授权标签及顶栏“打开交付中心”恢复 accessible name 保留，不批量替换所有历史术语。

### 新旧视图收敛（F87）

首页、Agent、任务、收件不再默认同时挂载新旧页面。Base UI 页签提供新工作台与明确命名的兼容视图，只有选中视图读取其专属数据；切换先经过既有草稿离开确认，完整身份/租户/空间改变重置选择。旧 `#/overview` 仍落原容量/活动观察，新 `#/home` 落个人首页；旧 `#/transfers` 与 `view=legacy` 落传输恢复，新 `#/tasks` 落任务投影；旧传输与收件互跳、顶栏传输按钮保留恢复路径。生产恢复键和原 operation 不变。

第一批只收敛页面编排和密度。F88 已补设备/自动化/能力三个正式路由：设备仅显示浏览器连接信号与宿主限制，自动化只读真实规则，能力页消费发现及显式只读检查；不将此提升为规则编辑/执行、原生设备或全站六视口通过。用户可访问的旧授权仍能创建、撤销与归档；不自动迁移权限。

### 3.1 每页数据、权限与恢复责任

下表对每页明确套用第 4 节全部 loading/empty/partial/stale/offline/forbidden/error 状态；不能只做 happy path。L/E/P/S/O 分别是加载、空、部分失败、过期、离线后的显示及恢复动作。主操作以上表为准，只有权限与 capability 均允许时可提交；不通过隐藏按钮代替服务端校验。

| 页面 | 数据真源 / 权限 | L / E / P / S / O 与恢复 |
| --- | --- | --- |
| 工作台 | workspace/home；本人可读空间 | L 分段骨架；E 上传首文件；P 失败段重试；S 显示 observed_at 后刷新；O 最近观察只读，写入等待在线 |
| 文件 | files/cloud entries/file-queries；当前目录 read，写动作独立授权 | L 列表骨架；E 新建/上传；P 仅失败页重查；S cursor 410 清选择重查；O 保留非秘密原 operation，恢复先 lookup |
| 预览 | 固定 content/file/version；read/download 分开 | L reader 占位；E 无选中返回列表；P 单项附件重试；S 旧版仍固定、失效不可偷偷切新；O 仅明确已有且受权缓存，恢复重鉴权 |
| 文件详情 | versions/audit/threads/private-note/links；各段 read 或专属 write | L 页签骨架；E 无活动正常显示；P 单页签重试；S 版本/授权变更重读；O 时间戳标旧，恢复不重载其它版本正文 |
| 知识库 | file-queries/document/properties/links；read+人工 write | L 表格；E 新建文档；P 链接投影失败不清正文；S base_version 409 保草稿比较；O 草稿仅内存，在线重读再保存 |
| 资源库 | resource-descriptors/checks、collection snapshots；read、显式检查权限 | L 列表；E 添加资源；P 单项检查重试；S 新版待检查；O 只读历史 receipt，不执行资源 |
| 集合 | 既有 collections/snapshots/favorites；可见成员+本人修改 | L 成员骨架；E 加受权成员；P 失权项安全隐藏；S revision 冲突重读；O 禁提交、在线再取 snapshot |
| 标签属性 | labels/suggestions/property-definitions；人类管理，建议独立 | L 字典；E 新建字段；P 个别类型只读；S definition/revision 冲突比较；O 不批量离线改字段，在线重审计划 |
| 搜索 | file-queries/content-queries；当前范围 read，分析需另同意 | L 明确查询中；E 已执行零结果可清筛选；P coverage 不全可改范围；S 水位/cursor 过期重新查询；O 保留查询输入不伪造结果 |
| Agent | agent-grants、agent-groups、agent-organizations、agent-invocations；本人管理，调用读取按范围 | L 卡片骨架；E 接入/空组添加；P 组织或调用失败分别重试；S revision 冲突保留表单重读；O 卡片有观察时间，禁止签发/轮转/管理，未知先查询 |
| 任务 | workspace/tasks + 原 Operation/Plan；原 read/confirm/execute 权限 | L 原 ID 占位；E 无任务正常；P 逐项回执；S plan_stale 重审；O unknown 不改 failed，在线 GET 原操作 |
| 收件 | inbox-submissions+固定 FileRef+archive operation；本人 read/decision/archive | L 列表；E 等待受权外部提交/人工导入；P 单个失败回查；S version/revision 冲突重读；O 待回查不重归档 |
| 存储 | cloud/readiness/index/usage/transfer；连接管理与文件权限独立 | L 段骨架；E 配置连接；P 断连段修复后重查；S 时间/覆盖落后显示；O 已知配置不冒充在线，复制恢复原计划 |
| 设备离线 | 已发现宿主 capability/受权副本引用；本人设备能力 | L 探索状态；E 无设备与 unsupported 分开；P 缺权限给宿主入口；S 副本旧版明示；O 不假在线/后台，在线重新鉴权 |
| 自动化 | automation-rules/原 intent；人工授权管理 | L 规则；E 新规则 dry-run；P 查看原逐项失败；S 策略变更重审；O 无宿主 blocked，重连只恢复原意图 |
| 回收站 | 既有 trash/retention/hold；restore 与危险清理独立 | L 列表；E 已清空；P 批次逐项错误；S 保留期限更新重读；O 禁危险动作。当前永久删除禁止，不因有 UI 设计放开 |

## 4. 共享交互合同

### 导航、选择和列表

- 点击目录进入；文件行单击选择，双击/Enter 打开；复选框多选，Shift 只选择当前已加载页范围。不得将“全选本页”冒充所有搜索结果。
- 跨页选择默认清除并提示；全量批操作必须由 Server 建立固定 snapshot，回显条数/排除项后再确认。
- 批量工具条原位替换默认工具条，高度不变；取消选择保持滚动和焦点。文件/资源/知识列表复用同一选择模型。
- 默认 50 条/页，服务端最多 200 为接口上限；UI 首版仅提供 25/50。目录 lazy load；图库缩略图懒加载；10,000 行不得全量挂载。
- 排序稳定（主键相等时按稳定 ID），筛选在确认后生效，取消还原；页码切换失效旧选择。返回预览前的查询、页码、视图、滚动、焦点。
- 当前页仅一个 aria-current=page，待办强调/计数不得复用当前页选中样式；v39截图的并存强调不作为双选中规范。
- 侧栏分组可折叠，当前页、任务/收件计数在折叠态保留；导航偏好只保存非秘密字段。重置偏好不重置文件数据。

### 浮层、对话框和表单

| 类型 | 行为 |
| --- | --- |
| Tooltip | 图标有 accessible name；400ms hover，键盘 focus 可见；手机不依赖 tooltip |
| 单元格浮层 | 单击选中；双击/Enter 展开，最大 320×240px 正文区；可选择复制；Escape 返回单元格，滚动/换版本/翻页关闭 |
| 非模态详情 | 背景正文可用，无全页遮罩，不陷获焦点；固定模式不遮住当前行 |
| 手机详情 | 全宽 sheet，返回恢复来源；正文滚动与底部动作独立；虚拟键盘不遮发送/保存 |
| 确认对话框 | 400px 上限；focus trap；明确目标、后果、主次按钮；危险按钮不自动聚焦 |
| 简单/复杂表单 | 520/640px 上限，手机留 12px gutter；dirty/saving/error 明确；pending 禁重复提交 |
| 连续操作 | 成功后在当前上下文显示结果和回执入口；失败不清空用户输入；toast 不作为唯一错误容器 |

### 错误与异步

| 状态 | 显示 / 动作 |
| --- | --- |
| loading | 结构稳定的 skeleton；aria-busy；详情切换可取消旧请求 |
| empty | 区分空空间、过滤无结果、尚未配置；一个主要动作 |
| partial | 可用部分继续展示，缺失范围/原因可见；重试失败部分 |
| stale | 显示原版本及变化原因；重新读取/重建计划后再确认 |
| forbidden | 无权访问的清晰页面；不显示旧缓存名称或总数，不无限 loading |
| offline | 已观察信息带时间；可读缓存带版本；写操作明确等待/回查，不离线伪造成功 |
| unsupported | 显示缺少能力及安全替代（下载/改用已支持入口），不隐藏必需需求 |
| error | 安全中文说明 + request/operation 稳定 ID + 针对性重试；不展示 raw Provider 错误 |
| unknown outcome | 先 lookup/get 原资源；禁止换 idempotency key “重试”写请求 |

切换用户、租户、空间、连接、目录、文件或版本时，使用请求取消 + context revision 双保险；旧响应不可更新新上下文。活动任务约2秒/空闲摘要约30秒轮询，同一资源不重叠；后台标签页暂停，回前台重新鉴权和读取；失败带抖动退避2/4/8/16/30秒并尊重更长 Retry-After，401/403停止自动重试；不因新事件在用户编辑中重置草稿。

## 5. 前端结构与持久化

```text
main.tsx → AppProviders → AuthGate → WorkspaceShell
  ├─ Sidebar / MobileTabs / Header / CommandSearch
  ├─ RouteBoundary → feature page
  │   ├─ FileBrowser + DirectoryTree + FileDetailsList
  │   ├─ PreviewWorkspace + existing safe reader
  │   ├─ Knowledge / Resources / Collections / Properties / Search
  │   ├─ Tasks / Inbox / Agents
  │   └─ Storage / Devices / Automation / Trash / Settings
  └─ DetailHost / DialogHost / FeedbackRegion
data clients → Server public contract → owner receipts
```

建议路径：`src/app/`、`src/features/<feature>/`、`src/components/`、`src/lib/`。仅有真实共享需求才抽组件；复用现有 UI 原语。严禁导入原型 `model.ts`、内存样本和 demo reset。新文件/API types 不成为权限真源。

服务端负责文件、版本、收藏/集合、标签属性、授权（含期限）、Agent 分组/置顶、决策和调用事实；客户端负责 URL、视图密度、面板宽度、临时选择与未提交草稿。IndexedDB 仅沿用有隔离键的非秘密恢复身份；敏感文档草稿默认内存，服务端保存/本机加密草稿能力另验。缓存、token、连接密钥、签名 URL 不混入同一个 store。
