# 紧凑工作区与可读性规范

本文是 `drivebridge-compact-workspace-v1` 已实现的 UI 合同；本地验证与已知边界见 [验收记录](compact-workspace-validation.md)。以两轮浏览器标注为输入；最新要求优先：统一小控件，同时保留文字、边框及内容区的必要距离。历史截图和旧验收结论不能替代本轮验收。

## 尺寸与视觉层级

沿用 Precision Pine、现有字体与深浅色令牌。桌面工具栏以效率为主，表格和表单以清晰阅读为主。

| 对象 | 合同 |
| --- | --- |
| 单行按钮、搜索、输入、下拉 | 桌面 32px；字体 14px；水平内边距至少 12px；同排高度差不超过 1px |
| 图标按钮 | 桌面 32×32px、图标 16px；触屏目标至少 44×44px |
| 普通业务表格 | 行高至少 48px，上下各至少 8px、左右各至少 12px；含双行信息的行至少 64px，按内容增高 |
| 表格内部控件 | 保持 32px；不得让控件上下直接接触行边界；表头排序按钮不额外嵌套厚边框 |
| 表格工具栏和分页 | 距外容器左右至少 16px；距相邻表体至少 12px；按钮间隔至少 8px |
| 表单 | 标签到控件 8px，字段组之间 16px，字段区到提交区 24px，取消/提交间 8px；弹层四周 20px，手机 16px |
| 正文层级 | 正文/控件 14px、辅助文字 12px、分区标题 16px、页面标题 20px；辅助文字不得靠降低对比度掩盖信息 |
| 容器 | 内容分区间 24px，控件圆角 8px、面板 12px；复合卡片与预览项由内容决定高度 |

32px 只约束单行控件，不约束表格行、菜单内容、文件卡、缩略图、预览舞台或多行按钮。表格中两行信息应同时可读，不通过压缩字体或裁切行高满足密度。现有个人密度偏好继续可用，但紧凑设置也必须满足上述最小留白。

表格行、表头、分页和表单分区的线条明确使用 `--ui-border`，不得回退 currentColor 或白色。普通行不显示高亮横线；hover 使用轻微背景变化，选中以背景及选择控件共同表达，键盘 focus-visible 独立可见。正文与辅助文字对比度至少 4.5:1；截图中的蓝色批注框不属于产品样式。

## 表格、表单与详情

表格使用同一搜索、筛选、列设置和分页结构。数字右对齐并使用 tabular-nums；名称左对齐，状态为文字徽标。名称可省略，但 title/详情可完整读取；标识短显示并可复制原始值。操作列可达，宽数据仅在表格内部滚动，外层页面不产生横向滚动。

服务端已分页时，通用表格不再叠第二套本地翻页。权限矩阵的成员分页与网盘列分页分别命名；当前维度单页时不显示无效上一页/下一页。搜索明确限定当前加载结果，不能冒充全局搜索。

表单保留可见标签，校验错误靠近字段，跨字段错误位于表单内。提交后等待结果并防重复；失败保留输入和当前抽屉，成功才关闭并刷新相关列表。固定底部操作区不能遮挡最后一个字段，取消不提交；可恢复关闭后焦点回触发器。权限矩阵和用户目录使用相同留白规则，不为“管理页面”额外压缩。

## 页面结构

### 独立管理与授权

```text
系统侧栏 → 管理与授权
标题 / 当前租户 / 身份状态
申请与审批 | 通知 | 访问记录 | 租户与权限 | 账号与恢复
当前分类工具栏
表格或紧凑列表 → 记录详情抽屉
创建 / 邀请 / 修改 → 表单抽屉
```

五类都可深链接。普通成员显示“我的邀请”“本人账号恢复”等真实能力；工作区菜单和用户目录入口进入同一页。标题区不堆整段说明，管理只读、审批后明确执行等约束靠近对应动作。团队成员和网盘管理进入既有团队工作区，租户邀请、角色、权限、恢复和应急动作完整保留。

抽屉桌面宽 480px，手机占满可用宽度；标题固定，内容内部滚动，操作区留白。租户/账号/管理范围改变立即清除旧选择、编辑内容和一次性结果，旧请求不得覆盖新页面。

### 网盘与团队目录：列表详情模式

这是新增模式，保留原卡片入口。未显式指定时默认列表详情；用户目录继续使用原用户表格与详情流程，不再构造第三种账号详情。

```text
类别 / 搜索 / 存储或状态筛选                 列表详情 | 卡片
可访问数量
名称、类型、归属、用量或成员数     │ 所选项目名称与状态
列表行                           │ 已知用量 / 配额或成员数
列表行                           │ 存储 / 归属 / 当前权限
                                 │ 打开网盘 / 打开团队
```

内容宽度至少 880px 时，列表 `minmax(0,1fr)` + 320px 详情；小于 880px 时保持全宽列表，行选择打开同一内容的详情抽屉。首个可见项目是默认摘要，空结果显示筛选说明；选择项被筛除或失去访问权后清空。单击选择，双击或 Enter 进入原完整工作区，每行及详情提供明确打开动作。卡片模式保留原单击进入。详情只读摘要，不自动上传、授权或修改配置。

网盘摘要展示名称、个人/团队归属、存储类型、连接状态、已用/预留/配额和当前访问角色；团队摘要展示名称、说明、状态、本人角色、可见成员与网盘数。未知、不可见字段明确说明，不补零。禁止列出隐藏租户对象、连接凭据或 Key 明文。

目录新增可选 layout/selected 参数；团队原六页详情和网盘文件路由保持。进入后浏览器返回恢复原筛选和有效选择。视图切换只改变呈现，不改变租户、空间或权限。

### Finder 工具栏与专注

```text
目录导航                            文件视图 │ 专注
搜索当前目录及子目录
上传文件  新建 ▾  分享目录          类型 ▾  排序 ▾  更多
```

新建菜单同时保留文件夹和文件，上传为唯一实心主按钮。按 Finder 内容宽度响应，小于 640px 将类型与排序放入“筛选与排序”，分享放入“更多”；窄屏所有动作仍可达。删除位置描述行，不删除存储能力与权限状态在相关详情中的说明。

专注按钮与四种视图按钮有分隔，不能成为第五种文件格式。新标签页带原完整上下文；专注窗口同位置可返回完整工作区。

### 分栏与画廊阅读

- 分栏的实际文件列宽 280–320px，其他目录列最低 240px；列容器内横向滚动，文字不横向推出行框。可见名称区域至少 160px，图标 24px，名称最多两行并保留扩展名；完整名称可在详情读取。
- 单击选择而非立即打开；文件夹、文件的双击/Enter 延续原进入/阅读行为。当前文件列不得只留没有操作入口的短标题；不改变文件夹单击选择合同。
- 可用内容宽度达到 880px 时，分栏右侧使用至少 320px 的所选文件预览区；不足时保持完整列表宽度，通过“打开阅读器”进入既有完整阅读器，不挤成不可读窄预览。
- 画廊由自适应预览舞台、名称/类型/大小标题和缩略条组成；桌面舞台最低 320px 高，窄屏最低 240px。缩略项宽 112px、图像区域 80px 高、名称最多两行，自适应整体高度，不使用 32px 普通按钮模板。
- 画廊明确提供“打开阅读器”，双击/Enter 等价；左右键切换文件，输入框、媒体控制和弹层内不劫持键盘。切换视图保留同一固定版本选择。
- 图片、PDF、文本、音视频复用现有阅读器。Office 转换等待、未知格式、加密或权限失效显示真实状态，必要时提供下载；不加载凭空生成的预览，也不因布局调整放宽 HTML 沙箱或文件权限。

### 资源态势

概览四项指标合成紧凑区，内容小于 640px 时两列；存储分布、传输和最近文件保持清晰行间距，空状态不强撑卡片高度。最近文件保留类型缩略图与原完整预览入口。

容量趋势与快照只有在内容区达到 880px 才双栏。快照将名称、占用、额度、时间分行；图例换行，坐标字号至少 12px，日期按宽度抽样。零值用零基线表示，未采集保留缺口；全部零值不显示 `0.5 B` 等人工刻度。浮层在边缘也不越界，键盘读数和数据表始终可用。采集和保留规则进入“统计说明”，默认仅显示最近更新时间。

## 控件状态与恢复

| 场景 | 用户可见结果 |
| --- | --- |
| 加载 | 保留区域尺寸，显示骨架或加载状态，不用 0 或无权限代替等待 |
| 无结果 / 无权限 | 分别说明筛选无结果、尚无资源或不可访问；提供清除筛选或返回列表 |
| 表单校验失败 | 关联字段提示，输入和选择保留；首个错误可聚焦 |
| 请求失败 | 当前区或抽屉内显示错误与原操作重试，不自动放大权限 |
| 部分成功 | 保留成功项与失败原因；传输沿原 operation 恢复，一次性审批清单的失败项核对最新版本后重新申请，不重放已执行清单或标成全部完成 |
| 提交中 | 按钮禁用且给出状态，不能重复提交；不依赖动画表达结果 |
| 详情对象失效 | 关闭旧详情或显示明确不可用，列表重新取权，不展示上个租户内容 |
| 缩略图或预览失败 | 类型图标、错误/不支持文案、阅读或下载可用路径 |
| 减少动效 | 菜单/抽屉完成相同状态变化，取消位移动画且保留焦点反馈 |

## 验证矩阵与执行

视口宽度覆盖 390、872、882、957、1213、1280、1440px，高度 963px；深浅主题各一轮，并覆盖侧栏展开/折叠。重点截图：管理页及抽屉、用户目录、团队权限矩阵、团队存储表单、网盘/团队列表详情、Finder 工具栏、分栏、画廊、概览和容量。

数据包含空列表、真实零值、null 未采集、100 字中文名称、长扩展名、长 ID、多行错误、有数据分页、部分成功和失效资源。至少使用图片、PDF、文本、音视频、Office/不支持类型验证可读路径；凭据展示面不截图。

布局断言检查真实 bounding box、computed padding 和边框颜色，不只查类名。正文对比度、行高、工具栏与表体间距分别验收；不把所有 48px 行强缩成 32px。外层页面无横向滚动；内部宽表/分栏滚动允许且不遮挡打开动作。

浏览器用例须先断言已登录身份具有测试网盘或所需团队权限。使用一次性、已正确初始化的本地 fixture；前置失败保留证据，不增加等待或跳过断言。默认 fixture 的 skipped 项不能视为治理验收通过。新增列表详情和阅读用例应加入同一 runner，不能另起测试框架。

每次 runner 输出本项目 `temp/integration-test-runs/<run-id>/`，保留 summary、命令、标准输出、标准错误、脱敏环境及截图 artifacts。完成前针对两轮标注逐项比较前后截图；严格 spec 校验只验证文档合同格式，不表示实现通过。本轮证据及失败修复归因见 [验收记录](compact-workspace-validation.md)。
