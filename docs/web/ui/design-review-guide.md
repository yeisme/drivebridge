## 按用户流程审阅

| 流程 | 页面顺序 | 视觉核对重点 | 正式行为依据 |
| --- | --- | --- | --- |
| 找文件与阅读 | 工作台 → 我的云盘 → 固定版本预览 → 详情 | 导航唯一选中、紧凑行、详情不挤没正文、返回保留焦点 | R02 / AC04–07；原型示例正文不代表真实文件 |
| 接入 Agent | Agent 空态 → 接入表单 → 卡片 → 调用/收件 | 长期默认、仅读取默认、目录范围、一次 secret 与普通详情分开 | R07/R14 / AC12–14、24–27；配置保存不执行任务 |
| 审核产物 | 收件 → 固定版本预览 → 接收 → 归档 | 接收与归档分步、目标冲突、可找到原操作 | R08 / AC17；不得以卡片消失推断已归档 |
| 审查计划 | 任务 → before/after → 确认 → 逐项结果 | 风险与影响可读、stale 阻断、partial 可恢复 | AC15–16；确认绑定 revision |
| 搜索资料 | 顶栏搜索 → 稳定结果/全页 → 文件 → 返回 | 输入与查询状态分离、覆盖不足、关闭回焦点 | R06 / AC11；“最近访问”不等于完整搜索命中 |
| 手机审阅 | 底部 Agent/任务 → 全宽详情 → 确认/返回 | 不依赖 hover、44px 热区、键盘不遮操作、单列长内容 | AC02–03、17、27；首页截图不能代替整条流程 |

## 非 happy-path 静态线框

以下为正式设计补充，不声称冻结原型已提供可切换状态。采用同一页壳和内容容器；状态不是另起一套页面主题。

```text
加载：   [当前目录 / 面包屑]              [上传：暂不可用]
         [固定行高骨架────────────────────────────]
         [aria-busy；保留标题和布局，不展示假的零文件]

空态：   [当前目录]
         此目录还没有文件
         [上传文件]  ← 仅在 capability 和权限均允许时出现
         过滤无结果则改为 [清除筛选]，不诱导重复上传

错误：   [当前目录]
         文件列表暂时无法读取。你的选择尚未提交。
         [重试读取]  [返回上级]     请求编号：安全标识
         不展示 provider 原始错误，不自动重放写请求

无权限： [文件不可访问]
         你当前无权访问此内容。
         [返回文件列表]
         清除旧正文、名称和计数；不无限转圈或保留敏感缩略图

结果未知：[原操作编号]  正在确认操作结果
         尚不能确认是否完成，请勿重复创建。
         [查询原操作]  [查看详情]
         恢复只针对原身份，不提供默认“重新上传一份”

版本冲突：[你的未保存草稿] | [当前服务器版本]
         文件已更新，尚未覆盖任何版本。
         [重新读取并比较]  [保留草稿返回]
         不将“确认”偷偷映射为强制覆盖
```

上述状态同时适用于手机全宽内容区。错误容器使用可感知文字与语义状态，不只改变颜色；提交错误关联字段，焦点移动到摘要或失败字段，恢复后回到稳定控件。loading 不强行移动焦点；非模态详情不陷获焦点，对话框需正确 trap 与 Escape 返回。

## 本轮视觉阅读发现

本轮直接查看了历史桌面工作台和手机 Agent 截图，而非重新运行浏览器：

- 桌面工作台与“我的云盘”同时有强背景强调，容易误认双选中。正式页面必须只有一个 `aria-current=page`；快捷入口或待办强调应采用不同样式，UI Spec 已要求这一点。
- 手机 Agent 空态在筛选、组织操作后才出现接入介绍；核心接入按钮固定在页头，可保持直接可达。引导区不应挤掉真实 Agent 列表，接入后改为紧凑提示。
- 手机长页需要滚动，因此不能凭 390×844 一张截图声明任务/调用/收件路径都可用；正式验证应包含滚动到底、底栏遮挡和软键盘高度。
- 视觉沿用松绿导航与中性文件工作面，不切为营销首屏，不新增大型 hero 或第二套组件系统。截图中的插画仅示例内容，不成为业务依赖。
