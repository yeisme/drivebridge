# 知识阅读空间交互规格

2026-10-01 · 设计待实施。复用 [个人工作台 UI Spec](personal-workspace-ui-spec.md) 与 Precision Pine，不另建 Reader 产品或设计系统。宿主、安全与类型见 [Electron 架构](../../architecture/electron-desktop.md)，Pinax 字段以其[人类阅读合同](../../../../pinax/docs/interfaces/human-reading-api.md)为准。多标签、分屏、Markdown 渲染和 Obsidian 式交互的正式 Web 交接见 [多笔记工作台正式实现规格](notebook-workspace-production-spec.md)。

## 1. 入口与边界

知识库是一等导航入口，不只是文件预览弹窗。路由使用现有 hash 解析：`#/knowledge`、`#/knowledge/search`、`#/knowledge/read`；参数仅 source_id/object_id/revision/anchor 与允许的筛选，不放绝对路径、secret、任意 URL。搜索词默认留会话，不自动持久化或放分享链接。旧文件、搜索及预览深链保留 alias，不偷换含义。

可由用户设置知识库为默认启动页；未设置保持原启动偏好。Pinax 来源仅本地 desktop 可绑定；普通 Web/PWA 继续原文件知识库，缺原生能力显示“在桌面客户端连接本地笔记”，不伪造本机目录访问。既有移动客户端需求保留，但本片不提供手机 Pinax 界面；手机走 Hermes。

普通 Markdown 仍由 DriveBridge 固定版本读取，不要求导入 Pinax。Pinax 来源始终通过 owner，文件入口命中受管对象时进入同一来源/对象；不能提供普通文件编辑、分享或标签覆盖来绕过 owner。

## 2. 共用布局与阅读参数

- 复用现有 WorkspaceShell、DetailHost、导航、表单、Base UI/shadcn 原语；主导航宽度沿用当前 UI Spec，不复制旧 client-shell 的历史尺寸。
- ≥1280px 可显示三栏：列表 280px（可调 240–360）、正文弹性、关系栏 280px（可调 240–360）。1024–1279 默认收起关系栏；768–1023 目录/列表为抽屉。<768 保持组件可访问的单栏降级，不等于手机 Pinax 产品验收。
- 正文默认 18px、行高1.75、宽度72ch/最大880px；字号14–26px、窄/标准/宽三档行宽。代码块横向滚动仅在块内，表格在自身容器滚动，不使整窗口横向溢出。
- 浅/深色、边框、间距、焦点和 motion 使用既有 tokens；字体为随包/系统字体，离线不向字体 CDN 请求。
- 专注模式收起导航/列表/关系栏但保留可达退出按钮与笔记标题；Esc 退出最近一层，不丢原焦点和位置。字号、主题、行宽是隔离的非秘密客户端偏好，不成为阅读完成事实。

## 3. 三屏与控件

### 阅读首页

```text
[知识库]  [来源切换]  [搜索]  [阅读设置]
[继续阅读：最近6项，更多]   [稍后读：最近6项，更多]
[最近更新：分页列表]       [置顶主题/项目：受权引用]
```

- 首次无来源：唯一主要动作“连接本地 Pinax vault”，取消选择不写 binding。已存在来源但暂不可用：重连/诊断，不再次 init。
- 连接流程：原生选目录 → 只读校验与受管范围影响摘要 → 人类确认 → guard/binding 持久化成功 → 首页。预览失败不保存半个来源。路径只在原生对话框和受信服务边界内出现。
- 继续阅读按最后成功保存 position 的时间降序，不以预取/hover 算阅读；尚未能保存明确显示本会话位置。
- 最近新增/更新使用 owner 时间及固定 ID 排序，不运行推荐模型。置顶主题只保存 owner 主题/项目引用，不创建另一套标签关系。
- 来源切换先取消旧请求和清正文；近期卡片不得泄漏失权来源标题。

### 搜索

```text
[返回知识库] [关键词输入] [来源] [项目] [标签]
[状态/覆盖与索引水位]
[标题 · 命中片段 · 更新时间 · 来源] × 当前页
[下一页 / 重新查询]
```

- 默认在当前来源搜索；多来源先切来源，不把 Pinax relevance 与文件查询分数混为全局排名。
- 输入300ms debounce，Enter立即查询；query上限512字符。旧请求 Abort+context revision 丢弃晚响应。
- 默认50项/max200；下一页使用 owner cursor。410 清选择并重新查询，不拼接两代结果。`index_unavailable` 展示诊断动作，不能显示“没有笔记”。不自动 refresh/rebuild。
- 点击或 Enter 打开选中项；Alt+Left/平台返回恢复关键词、筛选、cursor栈、选中项、滚动和焦点。未知总数不显示伪精确计数。
- 命中片段转义后高亮，不接收可执行 HTML；复制引用固定来源与内容 revision。

### 阅读页

```text
[返回] [标题/来源] [固定版本状态] [收藏] [稍后读] [复制引用] [专注]
[目录/列表]      [正文：按页追加]      [反链/来源/附件]
```

- 默认解析当前版后锁定 revision；新版本出现只提示“有新版本”，点击重开才切换。历史版不可达不能自动打开最新再声称原引用有效。
- 分段接近视口底部时加载下一页，同一文档最多一个在途页；显式“继续加载”是可键盘操作的回退。目录跳转由 owner anchor 定位，不把全篇一次加载入 DOM。
- 全文完成仅 `complete=true && next_cursor=null`；超预算以正文内状态说明和显式原文下载动作处理，不在截断后显示“已读完”。
- 目录大于512项分页；未知/失效 anchor安全回正文顶端并提示，不打开同标题的其他笔记。
- 反链与来源独立加载，失败不抹正文；关系只显示已授权 owner结果和水位。跳转后可返回精确原位置，不假设目标 URI 在另一 vault相同。
- 本地图片/PDF/媒体复用 reader。缺失、损坏、MIME不支持、无权、Range错误与超限各自可解释；未下载外部附件离线不可用。外链明确点击才能系统打开，不自动抓取。
- 收藏/稍后读要等应用服务确认再显示成功。滚动停止1秒或离页时保存 position，批次最多每2秒一次，采用相同未决 mutation 身份回查；失败标本会话未保存，不写正文。
- 保存阅读状态的 CAS 冲突先读取当前事实，保留本次意图，用户选择覆盖位置或沿用；不以客户端时间最后写赢。favorite/read_later单独字段更新，不能顺带覆盖position。
- 首片没有编辑/批准/整理主按钮；如显示后续入口必须 disabled并说明，不跳到文件写接口。

## 4. 状态矩阵

| 状态 | 可观察 UI | 恢复与禁止行为 |
| --- | --- | --- |
| loading | 区域骨架与明确加载对象；上一来源正文已清空 | 可取消/返回，不无限阻塞整页 |
| empty | 区分无绑定、无笔记、无命中、无稍后读 | 给一个相符的下一步，不显示假数据 |
| ready | 固定来源、revision与实际内容 | 操作由可用 capability 控制 |
| partial | 正文/关系/附件独立状态与缺项 | 不以局部成功标整篇完成 |
| stale | 当前版变化或索引水位落后 | 显式重新打开/查询，不静默切版 |
| forbidden | 清正文、片段、名称及媒体缓存 | 不提供旁路下载/旧端点读取 |
| offline | 本机来源继续可用；远程附件显示不可达 | 不自动发起同步/下载/付费 |
| unsupported | 显示缺失的合同/宿主/格式 | 禁用动作，无 mock fallback |
| error | 安全原因、原操作/请求恢复入口 | 未知 mutation先lookup，不能新键重试 |

## 5. 键盘、无障碍与隐私

Cmd/Ctrl+K复用现有搜索浮层并携带来源；进入正文后 Cmd/Ctrl+F仅搜索已加载页并明确范围，不伪装全文搜索。Tab顺序跟视觉一致，所有图标有名称；目录/反链是可聚焦链接，菜单关闭焦点回原控件，加载追加不抢焦点。状态采用适度 aria-live，不能每个滚动进度都播报。

200%缩放、长中文标题、长代码、320px组件回退、1024/1440/1920桌面宽度、浅深色、reduced-motion都有断言。正式Electron界面不在有preload的窗口中执行笔记脚本。正文/查询不进遥测，复制是用户明确动作；跨窗口/用户/session晚响应不能恢复旧正文。
