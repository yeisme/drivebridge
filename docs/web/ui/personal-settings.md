# 个人设置与主题

`#/settings` 供当前账号使用。显示名称保存到服务端，原 `name` 与用户 ID 保持不变。姓名输入按 Unicode 字符计数，允许 1–80 个字符，拒绝控制字符。提交失败保留输入；保存成功更新账户菜单，其他设备重新读取 `/me` 可见修改。

头像从当前账号个人网盘内不超过 2 MB 的 PNG、JPEG、WebP、GIF 图片中搜索选择，服务端绑定 `file:<file-id>:<version-id>` 固定版本。候选最多 30 项，前端查询防抖 250ms。头像引用不允许远程 URL、SVG、共享团队资源、待审核、回收站或加密空间内容。读取时重新检查归属，文件删除或权限撤销后回退为姓名首字；清空头像不删除源文件。

资料通过 `PATCH /api/v1/me` 更新，要求本人浏览器会话与 CSRF，Agent、服务身份、分享令牌不能修改。`GET /api/v1/me/avatar-options` 提供当前账号候选，`GET /api/v1/me/avatar` 提供私有头像内容。不得把头像访问扩展成公共文件通道。

浅色、深色、跟随系统、列表密度及减少动效继续保存于当前浏览器，复用现有 `drivebridge:*` 键。恢复默认外观不修改资料或凭据。浏览器拒绝存储时仍在当前页面生效，并报告无法持久化。

设置页使用 shadcn Card、Input、Combobox、RadioGroup、Switch 和 Button。右侧为外观、个人资料、账号信息大纲，替代原使用偏好说明卡；窄内容区大纲置顶。点击大纲不修改路由或清空编辑内容。移动端单列，表单失败、复制失败、加载、空结果均可见；测试截图不能包含登录 Key 或激活码明文。交互验收见 [本轮改进](interaction-polish.md)。
