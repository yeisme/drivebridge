# 文件阅读器与团队测试交付

## 阅读器

XLSX、CSV 与 TSV 的表格阅读能力、数据边界及验证说明见 [表格预览](spreadsheet-preview.md)。

Finder 分栏与画廊的阅读入口、长文件名和缩略项排版遵循 [紧凑工作区规范](compact-workspace.md)。它们复用下述完整阅读器和固定版本引用，不新增转换服务、不改变沙箱边界；本轮验收分别覆盖列表选择、长中文名称、键盘打开和真实阅读，证据见 [验收记录](compact-workspace-validation.md)。

PDF 使用本地 PDF.js 6.3.289 与同版本 worker；标准字体、CMap 和 WASM 资源随构建提供。原 PDF 与 Office 转换 PDF 共享同一组件。只渲染当前页，支持页码、翻页、缩放、适应宽度/整页与文本选择。密码只存在预览内存，文件切换销毁加载任务；不运行 PDF 文档脚本或 XFA。

加载状态以画布和文字层完成为准，明确显示密码错误、损坏、权限失效、文件不存在、网络失败和超时。下载继续由外层检查器与服务端授权决定。图片、音视频、SVG、文本和转换文档复用原有能力，未知类型不宣称可预览。

HTML 默认「安全预览」：禁用脚本，CSS 动画仍可能运行。「交互预览」允许文件内脚本，但仍为不透明沙箱来源，外部请求、父窗口数据、存储、设备和剪贴板均受限。界面不修改文件主题。适应宽度随舞台伸缩；实际大小提供 1024px 参考视口及水平滚动。HTML 源码读取限制 2 MiB，模式切换共享读取缓存。

文件列表、目录树及预览列表按钮采用 surface 布局，文件名左对齐，缩略图尺寸独立于通用按钮。未知缩略图保留文件类型图标。

## 团队管理

当前体验升级为团队治理。当前账号可创建团队、给新网盘指定自己为负责人、设置配额及调整已有网盘配额。负责人必须是该团队成员，调整配额不得低于已用与上传预留之和。管理员身份不替代本实例的显式内容授权。

yeisme 团队测试网盘配额为 1 GiB（1,073,741,824 字节），原个人网盘配额保持不变。网页按钮不是权限来源，所有操作由服务端校验。服务恢复与备份归 Server，参见其开发恢复文档。

## 验证

`pnpm test`、`pnpm build`、`pnpm test:e2e`。PDF 浏览器测试检查实际像素、文本、密码、损坏、403、中文、扫描件和 1440/1248/1098/882/390px。HTML 测试验证计数按钮、重新运行、源码和隔离边界。团队配额测试使用独立团队 fixture，预览实例验证仅操作获授权的 yeisme 测试空间。
