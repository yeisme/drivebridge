# 工作区去重与空间配额

本轮 UI 能力属于 client（fit）。配额、权限与统计仍由 Server 决定；本机统计不与服务端汇总合并。不新增数据库、扫描或存储后端能力。

## 导航与操作

顶部面包屑承担位置说明，页面保留屏幕阅读器标题；创建和授权操作进入顶部操作栏。网盘属性通过位置详情查看。工作台不重复展示品牌页脚。文件列表只保留一个真实表头，排序清空分页游标。空目录沿用工具栏上传按钮。

资源态势只有概览、容量、传输、机器人、安全审计一层 Tab，支持方向键及 Home/End。旧 analytics、users、agents 路由继续兼容。连接指南通过抽屉打开，签发完成仍显示配置下一步。复制配置仅表示复制成功，不表示已安装。

## 共享容量口径

侧栏、网盘卡片、概览排名与用量环形图使用 capacityOf。使用同次 spaces 返回中的 used_bytes、reserved_bytes 和 max_bytes；占用为已用加预留，剩余最低为零。已用不再次叠加版本和回收站。

缺失值保持未知；配额缺失或非正数不推算百分比。超额文字显示实际比例和超出量，图形最多填满。历史快照单独标注，不与实时额度拼合。图表保持未采集缺口，有效与观测传输分组展示，不相加。

用量弹层选择空间不切换工作区身份。打开刷新，每 30 秒更新；页面隐藏暂停，关闭中止，身份变更隔离响应。失败清空弹层旧数据。关闭后焦点回到入口。桌面弹层宽 360px，移动端为底部面板，折叠侧栏保留入口。

## 复合交互表面布局边界

导航项、网盘/团队卡片、指标卡、最近文件、容量入口和用量图例使用 Button 的 layout="surface" 模式承担交互及键盘语义，布局由各自的领域 CSS 决定。它们不是固定高度的行内操作按钮，surface 模式不附带 inline-flex、h-8、whitespace-nowrap 和通用 SVG 尺寸，避免组件迁移再次覆盖布局。普通提交、取消、工具栏动作继续使用公共 Button。

顶部「我的工作空间」可点击返回网盘入口。布局回归见 tests/layout-surfaces.spec.ts，覆盖浅色/深色下 882、1440、390px，验证图标对齐、侧栏溢出、网盘卡片分区、指标等高、容量行边界、近期文件和返回导航。
