# 文件浏览、媒体预览与分享

默认进入“我的网盘”。服务端网页和本机 `drivebridge view` 复用 Finder 风格的目录树、列表／图库、检查器、快速预览。统计保留在资源概览中。

## 文件体验

单击选中文件或文件夹，双击、Enter 或文件夹打开按钮进入目录；右键“查看元数据”打开检查器；空格或“详情”打开预览。上下左右方向键、上一个／下一个按钮与右侧缩略列表切换当前页中的文件，Esc 返回并恢复焦点。列表支持多选、文件拖拽移动、新建目录、重命名、复制/剪切/粘贴、创建副本、移动和回收站。复制与创建副本走服务端文件 copy 或 `POST /directories/copy`（目标仍是受管 S3 空间），完成记录进入传输中心。已连接 OneDrive 时，菜单提供「复制到 OneDrive」：文件走 export，文件夹走 `POST /directories/export`。generic rclone 仍只在本机 `drivebridge view`。同网盘剪切粘贴走文件 move 或目录前缀移动，可用撤销或 Ctrl/Cmd+Z 撤回上一次移动。Ctrl/Cmd+V 贴到当前目录；“粘贴到…”和“移动到…”用目录树选择目标。网页不自己翻页递归复制。跨网盘剪切禁用，同名永不覆盖。永久删除先展示 usage 影响并输入文件名确认，仍发送服务端确认头。列表按页读取，视图偏好和收藏只保存在浏览器本地，不保存凭据。内部剪贴板只存在于当前页会话。

服务端目录来自受管文件元数据和显式空目录。本机目录来自实际 provider 列举；owner 在线时复制、移动、回收文件夹走私有 `files/action`。owner 缺席时只显示已观察索引，标明非全盘清单并禁用写操作。普通文件读取不获取本机任意路径权限。

预览采用固定视口的左右分栏，右侧展示文件列表、路径、文件与版本标识；版本记录和跨网盘复制默认折叠。手机采用上方预览、下方信息布局。预览固定所选版本。图片在深色舞台上查看：滚轮／双击缩放（以光标为锚点）、拖拽平移、旋转与水平／垂直镜像、全屏，透明区域显示棋盘格；标注模式提供画笔／矩形／箭头、六色、三档粗细、撤销与清空，标注只存在于当前会话，可导出带标注的 PNG 副本（原文件不写回）。信息面板悬浮于舞台右上，可折叠，按文件类型提取：尺寸与格式、JPEG EXIF（相机／镜头／曝光／拍摄时间／GPS 坐标）、PNG 位深与颜色类型、文本行数与字符数；解析失败时静默降级，只显示基础字段。视频提供速度（0.25–2×）、逐帧步进、循环、画中画、帧截图与全屏；音频支持变速。SVG/ICO 走图片查看器，Markdown/代码/数据文件按扩展名识别为文本预览并统计行数。视频与音频使用原生播放器，PDF 使用阅读器。不兼容格式可请求转换预览，文件、传输卡片、分享页和文件卡片复用缩略图。浏览器不再先把整个视频读成 Blob。

## 专业格式与运行依赖

| 格式 | 处理方式 | 运行依赖 |
| --- | --- | --- |
| PNG/JPEG/GIF/WebP/AVIF/BMP | 浏览器原图；JPEG 缩略图 | 缩略图需要 FFmpeg |
| 浏览器支持的视频／音频 | 原生流式播放 | 原文件读取 |
| 不兼容视频 | 按需 MP4 副本 | FFmpeg，含 H.264/AAC 编码器 |
| PDF | 原生阅读；首页缩略图 | 缩略图需要 Poppler 的 pdftoppm 与 Bubblewrap |
| DOCX/XLSX/PPTX | 只读 PDF；首页缩略图 | LibreOffice、Bubblewrap；缩略图另需 pdftoppm |
| PSD/PSB/TIFF | 合成图预览 | FFmpeg 对该具体文件的解码支持 |
| DNG/CR2/CR3/NEF/ARW/RAF/ORF/RW2 | 标准显影预览 | LibRaw 的 dcraw_emu 或兼容 dcraw、Bubblewrap、FFmpeg |

格式适配不代表所有相机、图层、字体或 Office 特性都已实测。界面区分转换预览、组件缺失、失败与原文件；原文件不会被转换副本覆盖。旧版 Office、AI/EPS/CAD 不在首轮范围。

## 分享与 Key

文件页可分享所选版本或当前目录。固定交付不会自动包含后续新增与覆盖；持续共享跟随目录内容，但排除待审核结果。接收方可为指定用户或持链接的人，支持有效期、提取码、下载开关和撤销。仅预览不能防复制，已下载副本不能收回。

本机分享先复制至用户明确选择的远程空间，再创建链接。持续共享显示同步状态；本机离线时远程保留上次副本。远程目标连接需要用户凭据，Agent 文件授权不能创建分享。活动分享期间不允许静默更换为另一个远程账户。

用户 Key 与 Agent 授权的“删除并归档”会吊销访问并保留审计。默认隐藏归档记录，可切换显示。最后一个可用管理员 Key 不能通过归档入口删除。已启用的租户治理继续按其独立审批与权限规则执行。

## 产品边界

个人网盘、团队网盘与本机网页只提供文件管理、上传、预览、分享及固定版本引用复制，不提供“用于创作”、提示词编辑、@ 创作素材选择、模型连接配置或生成提交面板。创作与生成交互由 Eikona、Scaena 等领域产品承载。

复制固定引用不会授予访问权限。既有外部集成与文件回存服务合同保持兼容；网盘页面不承担创作工作台职责。

## 无账号本地体验

在本项目运行 `pnpm build`，然后从 `cli/drivebridge/server` 启动：

```bash
go run ./cmd/drivebridge-fixture --listen 127.0.0.1:10414 --public-origin http://localhost:10414 --web-dir ../web/dist --demo
```

打开 `http://localhost:10414`，点击“无需账号，进入本地体验”。使用独立临时空间和模拟存储，支持文件上传、目录与预览，不需要真实账号或密钥；服务关闭后清空。体验身份有管理权限，勿存放需要保留的资料。正式服务不提供该入口。

显式开启 `--demo` 后，本地模拟服务不再按浏览器 Origin 限制登录与操作，兼容 localhost、回环 IP 及开发代理／端口转发；仍使用会话及 CSRF token 校验文件修改。该宽松行为仅存在于独立的临时 fixture，正式服务不变。监听必须绑定回环地址；不要将体验服务作为真实资料服务或公开部署。`--public-origin` 可选，仅用于配置回环回调地址，体验入口无需与它完全匹配。

## 绿色工作区与身份关系

“我的网盘”先按个人／团队和存储筛选空间，再进入文件工作区。返回“全部网盘”不改变文件。主侧栏可折叠，Ctrl/Cmd+B 同样有效；目录树有独立的折叠按钮。移动端主导航保留图标名称，目录树可以按需展开。偏好仅存 UI 状态。

“总览”展示实际可见空间容量、当前传输、有效 Agent 数量及当前网盘近期文件。日期分析保留在“使用分析”，容量卡片表示当前快照，不冒充所选历史日期的容量。文件预览仍使用固定版本。

“用户与团队”展示成员、团队及可见 Key 的映射，团队管理沿用现有治理表单与服务校验。个人模式没有真实团队时显示未启用状态；不创建假成员或假权限。

“Key 管理”支持按名称／用户／标识搜索、状态筛选、当前登录提示、标签修改、详情、真实 Key 复制、再次复制与轮转。标签与用户名称分别维护；Key 所属用户不可重绑。已有管理员仍可撤销或归档凭据，治理模式则遵循账号恢复流程。关联顺序是 Key → 用户 → 团队成员 → 网盘授权，而不是直接把登录 Key 绑定到 team。非治理管理员可查看既有管理范围；普通用户和治理用户只看到本人的 Key 元数据。

视觉参考：https://ui.shadcn.com/docs/components/sidebar 。采用绿色主题和现有组件实现，没有引入新的 UI 框架或 Tailwind 迁移。

## Key 的复制与轮转

“复制 Key”复制可用于登录或 API 请求的完整密钥，不复制 ID。再次点击可重复复制；“查看 Key”默认遮罩，支持显示/隐藏和手动选择，关闭即清空面板状态。浏览器不将 Key 写入 localStorage、sessionStorage 或 URL。

只有本人可以取回和轮转 Key，管理身份不能读取他人的 Key。旧记录若没有可取回的密文，需用原 Key 登录一次或轮转后使用新 Key。轮转先展示影响：旧 Key 与其余会话失效，当前操作会话保持登录，用户、团队权限与有效期不变。

输入框、下拉框与筛选器统一绿色边框、圆角、聚焦环和禁用状态，保留原生键盘及移动端选择器。窄屏 Key 列表以卡片展示操作。

## 文件菜单与新建

空白区、文件和文件夹可右键操作；目录树支持目录菜单。键盘可用 Shift+F10 打开菜单、方向键选择、Escape 关闭，触屏可使用文件“更多操作”。菜单复用预览、下载、引用、复制、剪切、粘贴、创建副本、分享、移动、重命名和回收站能力，不提供未经服务支持的文件夹递归删除。快捷键在文件区生效：Ctrl/Cmd+C/X/V/D、Delete 打开回收站确认、F2 重命名、Ctrl/Cmd+Z 撤销上一次移动、方向键移动焦点；输入框、对话框和播放器不拦截。`?` 或 Ctrl/Cmd+/ 打开快捷键说明。

新建目录展示完整目的地，可开启多级路径和创建后打开。新建文件支持纯文本、Markdown、JSON 内容，受管网页可创建真实空文件，使用同一上传和版本系统；本机连接要求非空内容并交给已有后台传输。失败后保留输入，同名不会覆盖原文件。目录信息显示当前页计数和字节，文件检查器增加更新时间、网盘、文件及版本标识。

管理员账号操作默认输入目标用户名确认，也可选择本人 Key；最高管理员可接受明确的接管清单后接管并继续。工作区菜单显示当前身份和访问状态，管理和退出入口保持可达。

## 身份与工作区

普通成员侧栏保留日常文件与团队入口；本人 Key、私人存储连接与本人 Agent 授权从工作区菜单进入，仍由服务端按本人范围鉴权。用户目录仅向租户／平台管理员显示。管理中心保留申请、通知、访问记录，租户与账号事项通过“更多事项”选择，低频表单按需展开。

管理员打开非本人网盘会携带显式只读管理范围，旧链接可按当前服务端返回的可访问网盘自动补齐范围。不可访问的网盘显示返回入口，不渲染文件工具栏。此行为不会删除体验空间或其中的文件。

## 中文消息、历史与分析

`src/i18n.ts` 是中文错误、操作状态与新增界面消息的统一入口，默认 `zh-CN`。服务端错误码保持原义；未知错误使用中文兜底，不直接展示英文服务端消息或 Provider 内容。现有界面的固定中文文案可逐步迁入该入口，本轮不提供语言切换器。

传输中心与产物收件箱共用历史筛选组件，支持文件／任务／来源搜索、状态与来源筛选。清理仅收起当前筛选中的已完成、已取消记录，失败待重试和中断待恢复记录保留。浏览器保存按用户、租户和页面隔离的记录 ID，不保存文件内容或凭据；可撤销或重新显示。该偏好不跨设备同步，清理不删除服务端记录、文件或审计。

总览保留摘要与近期内容；`#/analytics` 独立承载使用分析，`#/insights` 保留总览入口。成功提示 5 秒后关闭，错误提示 12 秒后关闭；页面或空间切换立即清除旧提示，表单内错误保留原处理方式。通知中心及后台审计不因临时提示消失而删除。

## 专注网盘与直接操作

网盘页“在新标签页专注使用网盘”保留原网盘链接及权限范围，追加 `view=drive`。新标签页隐藏全局导航，只显示当前网盘；刷新仍保持专注模式，可返回完整工作区。它不创建另一个账号、分享授权或独立存储服务。

分析页标签在滚动时固定于顶部导航下方，切换标签会回到分析区顶部，并提供“顶部”按钮。用户目录直接提供新建用户、新建团队；Key 页直接提供新建本人 Key，默认有效期 90 天。新建用户仍走本人激活，不向管理员泄露其登录凭据。

传输与收件箱预览共用按操作空间和固定版本读取的逻辑，显示加载状态，15 秒超时后提供中文提示。旧记录引用的文件或版本不可访问时明确报错，不自动替换成当前版本。

## 网盘统一视觉与适配

完整工作区、专注网盘和本机文件页共用 `src/finder-browser.css`。进入网盘后以空间名为标题，导航、面包屑、搜索和视图切换合为一行；上传、新建、分享及筛选组成操作栏。窄文件区通过容器查询将搜索独立成行，手机网格保持两列，目录树可折叠。

卡片预览区固定为 4:3。缩略图不可用时显示文件类型图标和说明，文件名保留完整路径提示；桌面快捷操作在悬停或键盘聚焦时显示，触屏保持可见。可上传目录在拖入文件时高亮，只读目录明确提示不可上传。专注模式的文件区独立滚动，批量操作栏占据正常布局空间，底部统计不会被文件覆盖；通知也占据布局空间，避免遮挡工具栏。

验证使用现有入口：`pnpm test`、`pnpm build`，以及 `pnpm test:e2e tests/finder-design.spec.ts tests/finder.spec.ts tests/finder-actions.spec.ts tests/workspace.spec.ts tests/workspace-design.spec.ts tests/local-insights.spec.ts tests/direct-actions.spec.ts`。设计用例覆盖三个入口的桌面、平板与手机截图、主要文字对比度、缩略图失败、长名称、拖入反馈、触屏菜单和长列表选择；真实本机用例检查 owner 离线只读与在线操作。截图和运行结果均由测试入口保存到 `temp/integration-test-runs/<run-id>/`。
