# 团队工作区

团队列表与六页详情使用 `cli/drivebridge/server` 的真实治理服务。绿色工作区包含概览、成员、网盘、权限、活动和设置；详情 hash 可刷新、复制和前进后退。`#/teams/{id}/{tab}?tenant=...` 指定团队页面，`#/drive/{id}?tenant=...&team=...` 指定团队网盘；URL 只是上下文，不授予权限。既有 `#share/...` 格式保持原样。

## 页面布局

本轮 `drivebridge-compact-workspace-v1` 已实现：团队目录新增列表详情模式，保留卡片与既有六页详情；权限表恢复内容留白、使用低对比分隔线，避免同一维度的重复分页；设置表单按统一标签、字段及操作区间距呈现。细则见 [紧凑工作区与可读性规范](ui/compact-workspace.md)，不将下述历史压缩指标用于把文字或控件挤到边框。

顶栏直接切换租户；“工作区选项”按需展开管理空间、访问状态、管理中心与本地体验身份。详情直接显示团队名称，不再重复展示“团队”页标题。团队头部和横向页签随正文滚动，只有顶栏保持可见；页签可折为图标，窄屏可横向滚动。

中等宽度下主侧栏缩窄，并仍可手动折叠。统计卡片压缩留白，文件、成员与权限区域占据完整内容宽度。868px 窗口下，主操作区从距顶部 220px 以内开始，宽度至少 620px；移动端页面不产生横向溢出。

## 成员、账号与权限

团队管理员管理普通成员，租户管理员任命团队管理员并创建团队网盘，空间数据负责人处理协作授权。管理角色不会自动变成编辑权限。权限页的用户 × 网盘矩阵展示实际授权；本人无法自授权限。交接顺序为先增加继任管理员／数据负责人，再移除原负责人；最后一位保护由服务端同时覆盖旧接口。

已有租户成员可直接加入团队，但不自动获得网盘权限。其他账号先接受租户邀请，再接受绑定本人的团队邀请。成员页用一个「邀请加入」抽屉搜索用户：本租户成员默认直接加入，也可改为发送邀请；已有账号发出绑定邀请；平台管理员可开通空账号。开通后管理员复制交付说明（激活码、登录地址、两步加入），不是开放加入链接。被邀请人登录后在团队入口看到数量，列表上方一张下一步卡推进租户或团队接受，也可忽略。待接受的人出现在成员表。邀请可取消或续期七天。账号成功创建但邀请失败时，继续发送邀请即可，不会再次创建账号。仅站内通知，没有自动邮件或开放注册邀请。

Key 归用户，不归 team。页面按 Key → 用户 → 团队 → 网盘解释关系；本人 Key 入口回到个人凭据管理，团队管理员不能读取他人的 Key。团队 Agent 只显示授权元数据、空间和目录范围。

## 存储与归档

平台连接默认兼容已有团队。租户管理员可给团队分配本人在当前租户的 S3／COS 兼容连接；不复制或展示密钥，不能分配其他人的私人连接。新网盘选择已分配连接；使用中的连接不能取消分配。OneDrive 仅保留导入／导出，不作为团队受管网盘后端。已有网盘不原地迁移。

归档前显示成员、网盘、分享、Agent 和进行中任务影响。只读封存保留原读取权限和文件，禁止写入；活动分享、临时授权和 Agent 不随恢复自动生效。正在传输的任务按检查点停止，原操作者可取消未完成上传以释放预留容量。历史签发的存储 URL 仍可能存活到原到期时间；已下载副本不在可撤回范围。

修改使用团队版本号，409 后需刷新并重新确认。编辑抽屉保留打开时的版本，后台轮询不会掩盖并发变更。成员、邀请、网盘和活动分别分页；更改成功立即刷新，其余状态在页面可见时轮询。

## 本地团队体验

先在 cli/drivebridge/web 运行：

```bash
pnpm build
```

再在 cli/drivebridge/server 运行：

```bash
go run ./cmd/drivebridge-fixture --listen 127.0.0.1:10414 --web-dir ../web/dist --demo --governance
```

这是隔离、回环监听的临时体验。无需真实账号；在顶栏“工作区选项”中可切换团队管理员、数据负责人、普通成员，使用真实会话和权限。切换会撤销当前浏览器旧会话，多个身份同时验证应使用独立浏览器上下文。开发代理与本地端口转发继续可用；此入口不进入正式服务，关闭进程后临时数据清空。

## 用户目录与账号操作

用户页支持状态、角色、团队以及用户/Key 搜索。点击 Key 数量查看该用户的元数据；信息受限不表示 Key 数量为零。平台管理员可以在对应行冻结/解冻和删除归档；操作先展示影响与身份确认。归档保留文件及审计，恢复只回到冻结状态，不恢复旧凭据。

管理与授权中心的本轮目标为独立页面，表单和详情使用与视口适配的抽屉；原管理弹窗验收属于历史切片，不能证明新页面或表格留白达标。专用浏览器验证命令：`DRIVEBRIDGE_TEST_TEAM_DEMO=1 pnpm test:e2e tests/users-management.spec.ts`。
