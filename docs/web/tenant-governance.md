# 多租户管理与授权中心

当前界面：管理中心进入独立页面，五类入口可深链接；创建/修改和记录详情使用按需抽屉，团队成员与网盘管理复用团队页。详见 [本轮 UI 规范](ui/compact-workspace.md) 和 `drivebridge-compact-workspace-v1`。以下权限语义保持原义；审批、恢复、只读和租户隔离的验证见 [验收记录](ui/compact-workspace-validation.md)。

服务端通过显式治理引导启用后，Web 显示租户切换、管理空间选择和管理授权中心。用户可以跨租户，但各租户的个人空间、成员角色、通知与团队数据独立。上下文只存在当前标签页内存；切换会清空旧工作区并取消在途传输，旧响应不能覆盖新页面。

平台最高管理员可以查看全平台，租户管理员查看本租户，team 管理员查看团队空间。管理员能预览、下载和批量 ZIP 导出，但只读身份的上传、移动、删除、分享等按钮禁用。只读不是复制保护，下载副本无法撤回。前端只呈现权限，服务端始终重新校验。

管理中心包含：

- **申请与审批**：24 小时申请、1–8 小时范围授权，以及固定版本的删除、恢复、移动、覆盖和分享清单；批准后仍由申请人确认执行，逐项显示结果。最高管理员可复核身份后启动 15 分钟应急访问。
- **通知和访问记录**：查看汇总、下载／导出、申请处理、应急与恢复；离线保留，明确标记未读／已读。
- **租户与权限**：租户邀请需本人接受；团队管理员不自动拥有数据编辑权；空间数据负责人及备份审批人与团队管理分开。停用和移除保留数据。普通成员展示“我的邀请”，团队完整管理通过已有团队页面进入。
- **账号与恢复**：平台管理员开通空账号后，一次性展示激活码；本人在登录页生成登录密钥并激活。人工恢复仅供管理员核验请求，领取证明与新密钥不进入管理员页面。人工恢复后的特权需其他管理员重新确认。

页面在管理访问期间显示租户、空间、真实操作人和只读／已授权／应急状态。普通成员只见自己的空间和明确获授的团队空间。原有密钥管理页在治理启用后由新账号管理流程取代，不保留可冒充他人的旧重置入口。

没有恢复码时可申请人工核验；核验有误认风险。本人必须保存一次性显示的新密钥，刷新或关闭领取页面会丢失本次领取证明。OIDC 身份复核依赖服务端验证近期认证时间；无法复核时不降级放行。
